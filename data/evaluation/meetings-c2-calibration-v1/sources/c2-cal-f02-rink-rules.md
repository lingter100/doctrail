## 제빙 후 입장

제빙기가 빙면에서 나왔다는 보고만으로 이용객을 입장시키지 않는다. 시설 담당자가 빙면을 점검해 통과 기록을 남기고, 이를 확인한 세션 책임자가 입장을 승인해야 한다. 예정된 입장 시각이 되었거나 제빙 종료 뒤 시간이 지났다는 사정은 두 확인을 대신하지 않는다.

점검 중 잔수, 정리되지 않은 작업 도구 또는 이용 구역을 가로지르는 작업 동선이 확인되면 시설 담당자는 통과 판정을 보류하고 조치 내용을 남긴다. 조치 뒤에는 다시 점검한다. 세션 책임자는 보류 중인 점검을 통과로 간주하거나 앞선 세션의 입장 승인을 다음 세션에 그대로 적용하지 않는다.

## 역할과 일정 변경

| 역할 | 담당하는 판단과 기록 |
|---|---|
| 시설 담당자 | 제빙·보수 작업, 빙면 점검 결과와 실제 종료 시각 기록 |
| 세션 책임자 | 점검 기록 확인, 해당 세션의 입장 승인과 실제 시작·종료 기록 |
| 당직 책임자 | 세션 책임자와 조정 내용을 확인한 뒤 시각 변경·대체 운영·취소 확정 |
| 접수 담당자 | 확정된 변경 사항의 안내와 채널별 처리 기록 |

시각 조정안은 세션 책임자의 확인을 거쳐 당직 책임자가 확정한다. 다른 세션의 시작이나 종료에 영향을 주면 그 영향도 함께 기록한다. 새 확정 기록에는 변경 대상, 종전 시각, 새 시각, 적용 운영일을 남겨 이전 안내와 구별한다. 제안이나 검토 요청만으로 기존 일정이 바뀌지는 않는다.
