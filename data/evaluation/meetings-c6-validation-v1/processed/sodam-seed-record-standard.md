# 소담 씨앗기록소 표본 보관과 교환 기록 규약

이 문서는 평가를 위해 AI가 작성한 가상 조직의 기록이다. 실제 단체·품종·재배 지침을 나타내지 않는다.

2026년 3월 4일 확정. 기록소는 기증받은 씨앗의 유래와 관찰 이력을 보존하면서 소량의 지역 교환을 운영한다. 입고번호는 처음 받은 묶음의 식별자이며 발아검사나 소분을 거쳐도 바꾸지 않는다. 후속 수확물은 새 입고번호를 받고 원래 묶음을 부모 기록으로 연결한다. 기증자가 부른 이름은 채록명으로 남기며, 공식 품종명으로 확인된 것처럼 표시하지 않는다.

## 수량과 표본

봉투를 처음 열 때 보관 담당자와 기록 담당자가 함께 낟알 수를 센다. 균일한 상태의 씨앗 30립은 기준표본으로 따로 봉인한다. 기준표본은 교환이나 발아검사에 쓰지 않는다. 검사용으로 꺼낸 낟알은 결과와 관계없이 재고에 되넣지 않는다. 재고표에는 최초 수량, 기준표본, 검사 사용량, 교환 출고량, 교환 가능한 잔량을 서로 다른 칸에 적는다.

## 발아 관찰

교환 검사는 20립씩 두 접시에 나누고 14일째 정상 발아 수를 각각 기록한다. 두 접시가 모두 16립 이상일 때만 이 규약의 교환 기준에 해당한다. 평균만으로 한 접시의 낮은 값을 가리지 않는다. 환경 이상이 의심되면 위치와 온도 메모를 남기고 새 40립으로 다시 관찰할 수 있지만, 이전 결과를 삭제하거나 새 결과와 합산하지 않는다. 재검사는 같은 입고번호 아래 별도 검사번호로 연결한다.

## 교환과 공개 기록

교환 수령처, 출고 수량, 해당 검사번호는 보관 담당자 윤가람이 출고표에 적고 기록 담당자 한서윤이 재고 산식을 확인한다. 수령처는 다음 수확 때 채종 여부와 혼입 관찰만 회신하며 정해진 수량을 반드시 돌려줄 의무는 없다. 기증자의 실명과 정확한 밭 위치는 원본 동의서에 별도로 보관한다. 공개 목록에는 기증자가 허용한 지역 단위와 채록명만 싣는다. 동의 범위가 확인되지 않은 항목은 공개를 미룬다.

검사 기준을 충족하지 못한 씨앗도 유래 기록은 남긴다. 폐기를 하려면 윤가람과 한서윤이 사유와 실제 수량을 함께 기록해야 하며, 교환 보류를 폐기 결정으로 해석하지 않는다.
