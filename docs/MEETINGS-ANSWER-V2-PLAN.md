# 원문 인용을 먼저 작성하는 자연어 답변 후보

4B GGUF v1은 회의 분석을 회복했지만 자연어 답변의 인용·출시 상태·날짜·언어 gate를 통과하지 못했다. 기존 실행·소스는 `1b01139`와 원본 보고서에 보존한다. 이미 통과한 분석12호출을 반복하지 않는다.

후속 정책은 같은 모델·양자화·runtime·greedy·입출력 상한·질문·검색 후보를 사용한다. 변경은 다음으로 제한한다.

- 영어 예시 네 개를 제거하고 짧은 공통 지시만 쓴다. 테스트 사실을 담은 새 예시는 추가하지 않는다.
- 한국어 문자가 있는 질문은 `response_language=ko`, 나머지는 `en`을 명시한다. 서비스의 검증 대상은 한국어·영어다. 단순 문자 검사는 언어 품질 검증이 아니다.
- 각 주장에 대해 근거 ID와 원문의 정확한 연속 인용을 먼저 출력한 뒤 자연어 주장을 작성하게 한다. 서버는 그 ID 안에서 인용의 유일한 위치를 찾고 원문 절대 위치를 계산한다. 잘못된 인용·중복 위치를 거절하며 유사 매칭·인용 수선을 하지 않는다.
- 계획·예정·완료를 유지하고 회의 날짜를 사건 날짜로 임의 변경하지 않도록 한다. 질문의 요구에 빠짐없이 답하되 필요한 사실이 없으면 보류하게 지시한다. 모델의 자기평가를 정확도 검증으로 쓰지 않는다.

실행은 기존 입력 중 답변4건만 각1회, 재시도0이다. 새 계획으로 소스·입력 hash를 먼저 고정하고 raw 출력·실제 설정·실패를 보존한다. 완료된 M5-B 자료와 최종 test를 열지 않는다.

형식·원문 일치·의미 지지·질문 완전성·출력 언어를 나눠 별도 AI가 검토한다. 4/4 통과 후 전체 Java 운영과 실제 브라우저를 검증한다. 실패하면 이번 정책의 프롬프트/예시를 다시 고쳐 같은 사례에 반복 맞추지 않는다. 원문 선택 기능으로 대체해 자연어 답변 완료로 표시하지도 않는다. 회복된 분석·작업·권한·검색과 남은 자연어 답변을 구분해 후속 판단을 기록한다. 어떤 경우에도 이 개발 비교를 독립 평가·사용자 검수로 집계하지 않는다.
