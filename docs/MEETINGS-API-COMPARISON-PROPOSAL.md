## 필요한 이유와 무료 대안

무료 로컬 4B는 회의 발췌 요약과 관리 흐름을 통과했다. 같은 답변 정책의 9B 비교는 원문 인용 변형, 요구 정보 누락, 선택한 인용으로 뒷받침되지 않는 부연 때문에 실패했다. 이후 고정 C0 구간 ID 방식도 실제 4건에서 인용 9개를 모두 보존했으나, 의제를 수행 완료로 표현한 주장과 선택 인용 밖의 이유 때문에 의미 기준 2/4로 실패했다. 더 큰 모델이 해결한다고 가정하지 않는다. 알려진 네 질문에 프롬프트를 계속 맞추는 대신, 같은 C0 인용 구조에서 서비스 모델만 별도 비교한다.

무료 대안으로 원문 구간 ID 구조를 이미 구현·검증했다. 인용 변형은 해결했지만 의미 오류가 남았다. 비용을 쓰지 않는 동안에는 검증된 4B 회의 분석·결정/작업 관리·통합 검색을 유지하고 사용자 시연·운영 문서화를 진행할 수 있다. 자연어 답변을 관련 발췌 목록으로 바꿔 완료 처리하지 않는다. 같은 네 질문으로 새 로컬 모델·예시·문구를 반복 선택하지 않는다.

## 승인 요청 범위

추천 후보는 `gpt-6.1-sol`, Responses API, standard 처리, reasoning `low`다. 후보의 Structured Outputs 지원과 추론 수준은 [공식 모델 설명](https://developers.openai.com/api/docs/models/gpt-6.1-sol)을 확인했다. 서비스 후보를 개발용 Astra로 자동 지정하지 않는다. 이 후보의 실제 답변 품질과 지연은 아직 측정하지 않았다.

- 최대 24회, 자동 재시도 0회. 먼저 알려진 개발 사례 4회, 통과하면 별도 동결 계획의 새 질문 12회, 그것도 통과하면 Java 운영 확인 최대 8회다. 현재 일부 원문이 노출된 12문항을 엄격한 블라인드 자료라고 재사용하지 않는다. 각 단계 실패 시 뒤 단계는 실행하지 않는다.
- 요청당 입력 최대 8,192 tokens, 출력·추론 합계 최대 4,096 tokens를 예산 조건으로 둔다. 실행기에서 전체 직렬화 입력과 실제 모델의 토큰 계산 방법을 검증한 뒤에만 호출한다. 한도를 입증하지 못하면 호출을 보류한다.
- 전송 범위는 저장소의 이용 조건을 확인한 공개 문서 발췌와 AI 작성 합성 자료, 질문, 시스템 지시, JSON schema뿐이다. 개인 업로드·로컬 DB·세션·비밀값·검증 정답은 전송하지 않는다.
- 웹 검색·파일 검색·호스팅 도구·GPU 임대·클라우드 배포는 사용하지 않는다. `store=false`, 단일 요청, 서버 측 API 키 사용을 준비한다. API 키를 채팅이나 Git에 저장하지 않는다.
- 승인 요청 한도는 **API 사용료 US$2**다. 세금·카드 환산 수수료·계정의 최소 선불 충전액은 이 계산에 포함하지 않는다. 별도 충전이 필요하면 자동 결제하지 않는다.

## 예상 비용 — 실측 아님

확인일의 [공식 standard 가격](https://developers.openai.com/api/docs/pricing)은 100만 tokens당 입력 $2, cache write $2.50, 출력 $10이다. 캐시 할인은 가정하지 않고 입력 전체를 더 비싼 cache write 단가로 계산한다.

`24 × (8,192 × $2.50 + 4,096 × $10) / 1,000,000 = $1.47456`

이는 모든 요청이 한도를 채울 때의 보수적 계획값이다. 실제 사용량·반환된 모델 ID·요청 ID·추론 tokens·지연·실패를 기록하고, 실패한 요청도 예약한 비용을 소모한 것으로 처리해 재호출을 막는다. 가격과 입력 계수 방법을 실행 직전에 다시 확인한다. 가격 변경이나 처리 tier 불일치가 있으면 중단한다.

## 자료와 판정

기존 9B 실패 gate를 통과한 것으로 바꾸지 않는다. API 비교는 별도의 소스·입력·설정 고정 계획과 실행기를 만든 뒤 수행한다. 부모/프롬프트 작성자는 새 질문·정답을 읽지 않는다. 새 12문항은 현재 모델 호출 0이며, 독립 검토의 격리 한계도 함께 보존한다.

JSON 형식, 정확한 원문, 주장별 근거 지지, 질문의 필수 정보, 언어, 근거 부족 시 보류를 구분한다. [Structured Outputs도 내용 오류를 낼 수 있다](https://developers.openai.com/api/docs/guides/structured-outputs). 모든 필수 사례를 통과해야 Java 비교로 이동하고, 실패를 추가 튜닝용 새 평가 점수로 바꾸지 않는다. 비교 통과만으로 일반 정확도·최종 배포 완료를 주장하지 않는다.

API 전송은 외부 처리를 뜻한다. `store=false`가 모든 보관을 없애는 것은 아니다. 공식 문서에는 기본 abuse monitoring 보관과 별도 자격이 필요한 보관 통제가 설명되어 있다. [데이터 처리 조건](https://developers.openai.com/api/docs/guides/your-data)을 검토하고 공개·합성 자료만 사용한다.

현재 상태: 사용자 요청으로 보류, API 접근·키 확인 안 함, 네트워크 실행기 미구현, 실제 호출·사용료 0. 무료 C0 비교는 종료했고, 검증된 기능을 유지하며 별도의 무료 개선 작업을 계속한다.
