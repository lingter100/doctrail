## 해결한 문제와 선택

[이전 시작 진단](MEETINGS-FREE-QA-STARTUP-RESULTS.md)은 서버 준비 뒤 대화 형식 검증에서 실패했다. [고정 런타임 분석](MEETINGS-FREE-QA-RUNTIME-TEMPLATE-FIX.md)에서 lexer가 원본 template의 마지막 LF를 제거하는 표현 차이를 확인했다. 정확한 모델·런타임·원본 해시/크기 조합에서 서버가 반환할 표현을 별도로 검증하도록 수정했다. 임의의 공백 정리나 여러 변형을 포괄 수용하지 않았고 모델·질문·설정을 바꾸지 않았다.

외부 종료 확인에도 시간 경계를 보완했다. 알려진 프로세스만 원래 시작+300초 안에서 확인하고, 기한을 넘긴 조회는 부재가 관측돼도 성공으로 인정하지 않는다. 최초 모의14개 통과·독립 반례3개와 [수정19개 검증](../experiments/results/meetings-free-qa-startup-monitor-deadline-repair-v1.json)을 함께 보존했다.

이전 실행에서 부모 AI가 보존 대상 계획 문서를 갱신한 실패도 유지한다. 이번 실행은 Git 원문의 고정 사본을 사용하고 진행 문서는118개 변경 금지 목록 밖에 두었다. 소비된 v1 등록을 보존한 채 새 v2 등록을 사용했다.

## 해석과 남은 일

현재 고정된 조합에서 시작·설정 검증이 성공했다. 실제 props 본문은 운영 검증기가 폐기하므로 별도로 보존한 원문 template 해시는 여전히 UNKNOWN이다. 원래 중립 시험의 정확한 실패 원인을 이번 결과로 소급 확정하지 않는다.

이 결과는 토큰화·생성·회의 요약·답변 정확성을 검증하지 않았으며 QA 비교의 선행 성공으로 사용할 수 없다. 단일 실행 시간도 캐시·환경을 통제한 전후 성능 비교가 아니다. 프로세스 발견은 표본 관찰이므로 모든 짧은 수명의 자식을 포착했다고 주장하지 않는다. 유료 API 호출은0이며 로컬 전력·하드웨어 비용은 측정하지 않았다.

다음은 현재 실행기와 어댑터를 이용해 생성 경로를 확인하고, 조건을 충족한 뒤 아직 열지 않은 질문6개를 평가하는 최소 절차를 정하는 것이다. 닫힌 비교·소비된 등록을 재실행하거나 질문/기준을 튜닝에 사용하지 않는다. 무료 로컬 요약·답변 품질, 실제 모델을 포함한 최종 Java/React 흐름, 사용자 외관·사용성 검수는 남아 있다.
