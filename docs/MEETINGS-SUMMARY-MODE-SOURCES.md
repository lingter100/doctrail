# 추론 모드 진단용 공개 회의록 준비

이 문서는 자료 준비와 검토 범위를 설명한다. 실제 모델 결과나 자료의 최종 수용 기록이 아니다. [진단 계획](MEETINGS-SUMMARY-QUALITY-NEXT.md)은 같은 모델의 추론 모드 차이를 비교하며, 기존 검색 데이터셋·학습·격리 최종 평가를 대체하지 않는다. 독립 자료 재검토는 과거 실행–입력 연결 누락1건 때문에 수용 보류로 끝났으며 source-only 기준·실제 실행은 아직 없다.

## 선택과 원문 보존

자료 담당자는 선택 본문을 가져오기 전에 Wikimedia Foundation Governance Wiki에 게시된2005년 회의록 중 날짜순 첫4개를 선택하고 revision을 고정했다. 해당 사이트는 초기 기록이 모두 정식 이사회 회의는 아니라고 설명하므로, 모두 공식 이사회 전체 회의록이라고 표현하지 않는다.

독립 자료 검토는4개 페이지의 CC BY-SA4.0 표시와 출처·기여자 이력·변경 안내를 확인했다. 원본과 가공본에는 해당 출처와 이용 조건을 유지한다. 이 자료를 프로젝트 코드의 MIT 라이선스로 재지정하지 않는다. 전체 원본 bytes·렌더링·가공 과정을 보존하며 모델에는 회의 본문의 단어와 순서를 유지한 literal 표현을 전달한다. 사이트 탐색·언어 선택·머리말은 본문과 분리해 보존한다.

첫 문서는 렌더링과 raw literal 사이 실질 문자1개 차이가 있었다. 두 버전을 유지하고 직접 확인한 전체 raw literal v2를 기준으로 삼았다. 플랫폼의 렌더링 원인을 확정하지 않았다. 두 번째는 짧게 게시된 회의 요약 전체이며 별도 연결된 대화록은 포함하지 않는다. 원문의 오래된 안내 문구도 유지한다. 정답이나 길이를 맞추기 위해 문장을 고치거나 문제 단락만 뽑지 않는다.

## 과거 입력과의 관계

자료 담당과 독립 검토자는 본문·출처를 검토한다. 별도 custody는 승인된 원문 전용 필드와 메타데이터만 다루고, 부모는 해시·크기·집계를 확인한다. 이전 질문·정답·모델 출력으로 새 기준을 작성하지 않는다.

- 원문 전용38레코드, 명시된 단독 파일12개, 고정 코드의 원문 상수5개를 별도로 투영했다.55행의 exact/normalized 고유 해시는 각각49개다. 공개 metadata를 합친 normalized 값은64개다. 행과 해시의 수를 고유 문서 수로 바꾸지 않는다.
- 기존 선언22개 metadata 파일에서 원문 참조354행과 family 등록39행을 구분했다. 공개110행 중 raw 해시83행은 선언된 연결에서 확인됐지만 normalized 미제공68행은 그대로 남긴다. 이 중27행은 family 등록이고41행은 raw 해시만 있다.
- GGUF 답변 입력은 문맥 식별18행·6개 문서/revision 쌍으로 기록했다. 이를 전체 원문으로 승격하지 않는다. 과거 probe의7개 hash registry는 제품코드21개를 기록했으나 당시 실행·입력 결속을 증명하지 못했다.
- 현재 DB는 원본을 열지 않고 바이트를 확인한 별도 복사본에서 문서id/revision/source_kind3행만 확인했다. 현재 main 파일의 식별 정보이며 과거 실행 당시의 완전한 snapshot이라고 주장하지 않는다. 원문·질문·답변·분석 행은 읽지 않았다.

확인한 exact·normalized·긴 문단·선언된 가공/발췌 해시에서 새4개와의 관측 일치는0이다. 서로 다른 원문·가공 단계의 해시를 동일한 비교 지표로 합치지 않는다. 모든 번역·의미 중복이나 기록되지 않은 과거 사용의 부재를 증명하는 결과가 아니다. 구체적인 연결 누락과 일반적인 검출 한계를 분리해 독립 검토자에게 전달했다.

## 현재 한계와 다음 단계

한 조직의 과거4개 자료라 서로 독립인 표본이 아니며 국내 개발 조직의 실제 회의 전반을 대표하지 않는다. 사용자 직접 검수는0이다. 자료의 신규 프로젝트 사용 여부와 모델 사전학습 포함 여부도 다른 문제다. native 입력 토큰 적합성은 아직 실제 측정하지 않았다.

[독립7범위 재검토](../experiments/results/meetings-summary-mode-source-review-v1.json)는 원문 내용·출처 적합 판단과 별개로 L2 실행–입력 연결 누락 때문에 수용을 보류했다. 보존된 rawv10/v11의3개 선택자를 확인했지만 제품코드 해시6행·문맥 식별3행만 있어 당시 전체 입력 버전은 복원하지 못했다. 유한한 조사를 여기서 닫고 원래 보류 판정을 유지한다. 현재 보호 split의 직접 분리 여부는 별도 메타데이터 검토로 확인하며, [전향적 추가 계약](MEETINGS-SUMMARY-MODE-PROVENANCE-BOUNDARY.md)은 설계로 수용했지만 새 자료 수용 결정은 아직 없다. 이후 모델 출력 전에 원문별 핵심·조건·예외·현재 상태·시점의 기준을 별도로 잠근다. 실제 실행 후 개별 후보 판단을 먼저 잠그고 쌍·자기검토·시간을 공개한다. 현재 수용이나 실행을 미리 완료로 세지 않는다.

로컬 근거는 `.local/meeting-summary-mode-sources-v1/`, `.local/meeting-summary-mode-independent-v1/`, `.local/meeting-summary-mode-prior-source-inventory-v1/`에 원본과 수정 전 실패를 포함해 보존한다. 선택·원본·파싱·검토의 증거와 최초 버전 대조 실패도 삭제하거나 성공 기록으로 바꾸지 않는다. 재현용 공개 입력 묶음과 최종 freeze는 수용 후 별도로 준비한다.
