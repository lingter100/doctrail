# 로컬 QA 지침 후보의 실제 비교

2026-10-27 · 실제 실행·별도 AI 내용 판정 완료 · 서비스 채택 없음

문제는 정확한 인용이 붙어도 질문의 필수 내용을 빠뜨리거나 선택한 근거가 문장 전체를 지지하지 못하는 것이었다. [사전 계획](MEETINGS-LOCAL-QA-CONTROL-NEXT.md)에 따라 QA에만 질문 전체 요구와 주장별 근거 선택을 점검하는 고정 지침을 추가했다. 모델·원문4개·질문4개·평가 기준·요약 정책·출력/시간/자원 한도는 v6와 같다.

[구현 근거](../experiments/results/meetings-local-qa-control-implementation-v1.json)의237합성검사·독립 코드 검토와 [정확 소스 CI](../experiments/results/meetings-local-qa-control-source-ci-v1.json) 후 새 schema5 등록으로 한 번 실행했다. 공식CLI는90.781초 후 exit1, 관찰기는 정상 종료했다. 같은 실행을 재시도하지 않았다.

형식 통과와 정확한 인용 문자열은 답변의 완전성이나 근거 지지를 보장하지 않았다. 유효 답변4개 전부를 사전 포함 규칙대로 판정했고, 원문을 수리하거나 좋은 답변만 고르지 않았다. 개별 판단을 먼저 잠근 뒤 집계했다. 부모는28참조를 바이트 해시로 확인했으며 비공개 원문·질문·판정 본문은 읽지 않았다. 판정자는 과거 개발 출력과 자동 문맥에 노출됐으므로 완전 맹검이나 사람 검수로 부르지 않는다. 사용자 검수는0이다.

[v6 비교](MEETINGS-LOCAL-SUMMARY-CONTROL-RESULTS.md)에서도 수용0/4였고, 이번에도0/4다. 선택 근거 지지는 충분0/부분3/미지지1에서0/2/2, 필수 내용은 충족1/부분7/누락4/오류1에서1/4/6/2로 관측됐다. 지침 변경의 개선 근거가 없으며 해당 사례 집계에서 일부 항목이 나빠졌다. 반복 개발 질문4개·고정 순서·AI 판단·과거 노출이므로 통계적 유의성이나 일반 모델 성능 저하로 확대하지 않는다.

[공개 집계](../experiments/results/meetings-local-qa-control-actual-v1.json)는 실행·구조·내용 평가를 구분한다. 요청 상한 합계4096토큰은 실제 생성 토큰 수나 비용이 아니다. 유료 API·GPU 임대·클라우드는 사용하지 않았고 전력·장비 비용은 측정하지 않았다. 이 실험은 전체 원문을 준 개발 진단이며 검색·권한·문서 변경·화면이 결합된 최종 서비스 평가가 아니다.

사전 계획대로 **같은 QA 지침 계열의 미세변형은 종료한다.** 닫힌 실행을 반복하거나 기준을 낮추지 않는다. 다른 무료 로컬 접근을 별도로 설계하며, 요약은 [고정 엔진 검증 준비](MEETINGS-LOCAL-SUMMARY-ENGINE-VALIDATION-PLAN.md)로 출력 제약의 실행 가능성을 먼저 확인한다. 이 검증도 내용 품질이나768토큰 내 완결을 보장하지 않는다. 전체 목표와 회의1차는 미완료이며 계속 진행한다.
