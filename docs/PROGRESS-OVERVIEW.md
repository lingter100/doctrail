# 사용자가 보는 현재 진행 상황

기준일: 2026-10-30. **문서·회의 관리와 화면 연결은 구현했으며, 무료 로컬 AI의 답변·요약 품질과 최종 운영 검증이 남아 있다.** 회의 지능형 관리 1차와 전체 포트폴리오 목표는 진행 중이다. 완료율을 숫자로 계산할 근거는 없다.

사용자가 체감하는 핵심 미완료는 “회의를 넣으면 믿을 만한 요약과 답변이 나오는가”다. 관리 기능과 많은 회귀 검사가 있어도 이 부분을 대체하지 못한다. 로컬 모델의 내용 실패와 실행 환경 오류를 해결하는 과정에서 실행 통제·검토 절차도 지나치게 커졌다. 고정6개 질문의 기준/후보 실측은 끝났고 독립 AI 내용 수용은 두 모델 모두0/6으로 끝났다. 후보를 채택하지 않고 비교를 종료했다. 완료된 검사·실험을 반복하거나 준비 문서만 늘리는 대신 이 비교를 끝내고 실제 서비스 연결로 진행한다.

## 지금 해결하는 문제

최근 [3B 모델 비교](MEETINGS-LOCAL-QA-CONTROL-RESULTS.md)는 답변 4개 모두 필수 내용·근거 기준에 미달했다. 인용 10개는 원문과 같았지만, 필수 내용 13개는 충족 1·부분 4·누락 6·오류 2였다. 정확한 인용 문자열만으로 충분한 답변이라고 판단할 수 없다는 결과다. 고정 개발 질문의 결과이며 일반 정답률로 확대하지 않는다. 요약 4개는 출력·문자 수 제한으로 거부돼 의미 평가를 하지 못했다.

지침의 미세변형 계열은 종료했다. [새 비교 설계](MEETINGS-FREE-QA-NEXT-DECISION.md)에 따라 새 7B 자산과 실제 출처 6계열·10문서, 질문·기준 6개를 준비하고 별도 AI 사전 검토를 마쳤다. [자료 준비](MEETINGS-FREE-QA-SOURCE-PREPARATION.md)는 실제 원문·합성 중립 입력·AI 검토·사용자 검수를 구분한다.

그러나 [새 7B 중립 시험](MEETINGS-FREE-QA-NEUTRAL-RESULTS.md)은127.044초에 생성0으로 실패했고 정확한 원인은 미확정이다. 안전한 진단 정보를 보완하고 별도의 [생성 없는 시작 진단](MEETINGS-FREE-QA-STARTUP-RESULTS.md)을 실제로1회 수행했다. 이번에는 서버 준비 확인 뒤 설정의 대화 형식 검증이 실패했다(외부 관측29.338초·생성0). 외부 보존 확인의 관찰 공백·부모 문서 변경도 실패로 남겼으며, 나중 알려진 잔여 프로세스 부재를 별도로 확인했다. 이후 [고정 런타임의 template 표현 차이](MEETINGS-FREE-QA-RUNTIME-TEMPLATE-FIX.md)를 보완했고 관련273개·독립 검토·게시 CI를 통과했다. 이후 [별도 v2 실제 진단](MEETINGS-FREE-QA-STARTUP-V2-RESULTS.md)은 health·props1회·정상 종료·전체 보존 확인을 통과했다(CLI19.906초·생성0). 시작 설정 오류 수정의 실측이다. 이어 [새 중립 생성 실측](MEETINGS-FREE-QA-NEUTRAL-V2-RESULTS.md)은 생성1회·유효1개·정상 종료·전체 보존 확인을 통과했다(실행21.031초·정리0.609초). [호출 전 인자 오류](MEETINGS-FREE-QA-NEUTRAL-PRELAUNCH-V2.md)는 CLI0·once 미소비로 별도 보존했다. 회의 질문의 내용 품질은 아직 검증 전이다.

요약의 [문법 엔진 준비](MEETINGS-SUMMARY-ENGINE-V3-PLAN.md)도 별도 진행 사항이다. 앞선 취득 2회는 시간 한도로 실패했고, 다음 취득의 제어·정리 경로를 수정·검토했다. 이후 실제 v3 취득1회는 LLVM 필수 하위 경로 검사에서54.484초에 실패했다. 다운로드와 부분 산출물·오류·소비 기록을 보존하고 소유 프로세스 종료를 확인했다. [실제 취득 실패](../experiments/results/meetings-summary-engine-v3-oct30-acquisition-v1.json)를 바탕으로 실제 압축 파일과 경로 검사 차이를 확인한다. 컴파일·엔진·요약 내용 검증은 아직 하지 않았다. [실패와 재개 검증](../experiments/results/meetings-summary-engine-v3-resume-v1.json)을 유지한다.

## 현재 검증 근거

2026-10-30 후속: 기준 모델의 실제 비교 시도는 질문을 보내기 전 대화 형식 검사에서 멈췄다. 생성0·6개 모두 미실행이며, 원인은 서버의 실제 template 변환을 기준 모델 검증에 반영하지 않은 코드 결함으로 확인했다. 정확한 매핑과 공개 fixture 회귀 검사를 보완했고 독립 검토를 통과했다. 저장 대기 경합을 고친9236b85는 양쪽 전체 CI를 통과했다(Python5,384·브라우저158). 수정된 소스의 새 중립 생성1회도 정상 종료·보존 확인을 통과했다(30.312초). [중립 실측](../experiments/results/meetings-free-qa-paired-v3-neutral-v1.json)은 실행 경로 성공이며, 기준6개·후보6개 실제 실행도 끝났다. 형식 유효는3개·4개이며 두 모델 모두 입력/출력 한도 거절이 남았다. 독립 의미 수용은 두 모델 모두0/6이었다. [최신 실측과 한계](MEETINGS-FREE-QA-PAIRED-V3-RESULTS.md). [실측과 원인](MEETINGS-FREE-QA-BASELINE-STARTUP-RESULTS.md). 이 비교는 실패 결과로 종료됐으며 서비스 품질 수용은 미완료다.

- 게시 `d982755`의 [필수 CI](../experiments/results/meetings-free-qa-neutral-results-ci-v1.json): 양쪽 실행의 backend/web/java-service 통과. Python 5,360개 통과·21개 제외, 전체 브라우저 158개 통과·실패 0, 실제 Java 운영 검사 통과. **회귀 검사이며 실제 모델의 의미 품질을 증명하지 않는다.**
- [질문 기록·피드백](MEETINGS-KNOWLEDGE-HISTORY-VERIFICATION.md): 현재 권한·문서 버전 재검사와 검색 범위 복원. 최초 실패와 수정 후 검사를 구분했다.
- [회의 항목 보정](MEETINGS-MANUAL-CORRECTION-VERIFICATION.md): 실제 Java·화면의 항목 추가/삭제/취소·근거 선택·담당자 편집. 합성 AI 응답 검사와 실제 모델 품질은 별도다.
- [백업·복원](MEETINGS-RESTORE-VERIFICATION.md): 실제 Java의 합성 자료 운영 12항목과 관련 회귀 검사. 공개 배포나 실사용자 부하 검증은 아니다.

이 검증을 새 모델의 정확성·사용자 검수·공개 서비스 배포 완료로 표시하지 않는다. 실패 후보는 기본 서비스 모델로 채택하지 않았다.

## 다음 순서

1. 실제 비교는 종료했다. 모든 유효 출력의 독립 의미 판정을 마쳤고 한도 거절과 내용 오류를 분리했다. 두 모델 모두 원래6/6 선택 조건에 미달했으므로 이 비교를 닫고 자동 다음 모델·프롬프트 탐색이나 같은 질문 재튜닝을 하지 않는다.
2. 무료 로컬 요약·답변이 개발 수용 조건을 충족하도록 진행하고, 그 뒤 격리 validation과 최종 평가를 수행한다. 최종 평가 질문으로 튜닝하지 않는다.
3. 실제 모델을 포함한 전체 화면·권한·문서 갱신/삭제·백업/복원·새 환경 실행을 확인한다. 외관·사용성 사용자 검수는 별도로 남긴다.
4. 비교·실패·한계를 정리해 최종 시연, 소개와 면접 설명을 완성한다.

기존 추가 2~4주는 잠정 계획 범위였으며 현재 보장된 완료일이 아니다. 가장 큰 변수는 무료 로컬 모델이 내용 품질 조건을 충족하는지다. 실제 비교 결과를 확보한 뒤 일정을 다시 판단한다.

녹음·STT·실시간·외부 회의 연동은 1차 완료 후다. 유료 서비스는 사용하지 않으며 공개 서비스 배포는 별도 승인·검증 사항이다. 세부 기록은 [STATUS](STATUS.md), AI와 사용자 역할은 [CONTRIBUTIONS](CONTRIBUTIONS.md), 완료 기준은 [회의 설계](MEETINGS-DESIGN.md)에 남긴다.
