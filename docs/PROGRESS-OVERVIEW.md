# 사용자가 보는 현재 진행 상황

기준일: 2026-10-23. 문서·회의 관리의 기본 기능은 구현돼 있으며, 무료 로컬 AI의 요약·답변 품질과 전체 운영 흐름을 완성하는 중이다. 회의 지능형 관리 1차와 전체 포트폴리오 목표는 미완료다. 상세 이력은 [STATUS](STATUS.md), 완료 기준은 [회의 설계](MEETINGS-DESIGN.md)를 따른다.

## 지금 집중하는 문제와 다음 확인

회의 요약에서 조건·예외·적용 시점을 빠뜨리거나, 선택한 인용이 요약 문장의 일부만 뒷받침하는 문제가 남았다. 단순한 발췌 선택 개선은 네 요약의 핵심 충분성을 개선하지 못했다. 그 뒤 실제 생성 요약 두 건을 독립 AI 기준으로 검토했지만 두 건 모두 핵심 충분성이 부족했다. 인용 위치가 맞고 모델 자기검토가 통과해도 요약이 충분하다고 볼 수 없었다.

이에 조건·예외·시점 등 관계의 양끝 원문을 먼저 연결하고 요약 주장과 인용을 같은 관계 묶음에서 도출하는 후보를 구현했다. 기존 Java/React 저장·표시 계약과 구형 기본 동작을 유지하며 명시적으로 선택한다. 모듈·서비스의 관련 합성 회귀761개와 Ruff, 독립 코드 검토를 통과했다. 모듈257개는 이761개에 포함돼 합산하지 않는다. 실제 비교 실행기의 합성 검사·독립 읽기 검토도 마쳤다.

소스23d67b5의 push/PR 필수 CI와 실행 설정 확인 뒤 실제 로컬 모델로 한 번 비교했다. 두 회의의 요약 저장·원문 근거 이동까지 진행했지만 세 번째 분석의 자동 근거 검토가 요약을 거부해 전체 실행은 실패했다. 질문6건은 실행하지 않았다. **독립 AI 검토에서 핵심이 충분한 요약은1개, 부족한 요약은2개였다. 다만 세 요약 모두 일부 문장이나 선택 인용에 문제가 있어 전체 승인된 요약은 없다.** 작은 합성 개발 자료의 결과이며 사용자 검수나 최종 평가가 아니다. 정상 종료와 원본 보존을 확인해도 전체 실패를 통과로 바꾸지 않는다.

- 검색 기준·후보 선택·미세조정의 개발 비교를 수행했다. 일부 회수 지표가 좋아졌지만 다중 문서 질문은 악화된 결과도 있다. 개발 결과만으로 최종 성능이나 기본 모델 채택을 확정하지 않는다. [M3](M3-ANALYSIS.md), [후보 개선](M3-CANDIDATE-ANALYSIS.md), [M4](M4-MAIN-DEV-ANALYSIS.md).

## 남은 순서와 일정

1. 자기검토 대조에서 확인한 누락을 바탕으로 초안·원문을 다시 대조하는 재작성 후보를 구현한다. 같은 요청의 초안과 최종본을 비교해 충분성과 근거 연결이 실제로 좋아지는지 확인한다.
2. 공개 실제 자료의 출처·권한·전체 색인을 유지하며 정해진 calibration 통과 뒤 격리 validation과 최종 평가를 수행한다. 실패한 실험이나 잠긴 기준을 덮어쓰지 않는다.
3. 문서 권한·갱신·삭제, 실제 모델을 포함한 전체 화면, 오류 복구·종료·재시작·새 환경 실행을 검증한다. 사용자 외관·사용성 판단을 별도로 기록한다.
4. 기준/개선 비교와 실패 분석, 시연, 간결한 소개·면접 설명을 정리한다. AI 작성·검토와 사용자 결정·검수를 구분한다.

1차 기능 안정화와 지원용 포트폴리오 정리에 **추가2~4주를 잠정 계획 범위**로 설명했다. 실측 개발 속도로 계산한 납기나 보장된 완료일이 아니다. 무료 로컬 모델의 품질 개선이 가장 큰 변수이며 다음 실제 비교 결과로 다시 판단한다. 전체 완료율을 숫자로 산출할 근거는 없다.

코드·합성 검사·실험 준비의 완료를 사용자 기능 완성이나 실제 AI 품질과 같은 성과로 세지 않는다. 외관과 사용성은 최종 완료 기준에 포함한다. 녹음·STT·실시간·외부 회의 연동은 2차 범위로 제외하고, 유료 서비스는 사용하지 않는다.
