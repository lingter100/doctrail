# 사용자가 보는 현재 진행 상황

기준일: 2026-10-28. **문서·회의 관리 기능은 대부분 구현됐고, 무료 로컬 AI의 내용 품질과 운영 안정성을 검증하는 단계다.** 회의 지능형 관리 1차와 전체 포트폴리오 목표는 아직 미완료다. 완료율을 숫자로 계산할 근거는 없다.

화면의 완성도도 완료 기준이다. 실제 Java와 합성 모델 응답의 화면 검사는 서비스 연결 증거이며, 실제 모델 정확성이나 사용자 검수를 대신하지 않는다. 공개 서비스 배포는 별도 승인·검증 사항이다.

## 지금 시간이 필요한 이유

가장 큰 불확실성은 무료 로컬 모델의 내용 품질이다. [최신 실제 비교](MEETINGS-LOCAL-QA-CONTROL-RESULTS.md)에서 요약4개는 출력·문자 수 제한으로 거부됐다. 답변4개는 형식을 통과했지만 별도 AI 내용 평가에서 모두 필수 내용·근거 기준을 충족하지 못했다. 인용10개는 원문과 같았다. 따라서 정확한 인용 문자열과 충분한 답변을 구분해야 한다.

이는 고정 개발 질문4개의 결과이며 전체 모델 정답률로 일반화하지 않는다. 요약은 유효 출력이 없어 의미 평가를 하지 않았고 사용자 검수도0이다. 실제 로컬 생성이 실행된 것과 제품 품질이 완성된 것을 구분한다. 실패 후보는 서비스에 채택하지 않았다.

요약 분량 제어와 QA 지침 변경은 실제 비교까지 마쳤지만 수용을 개선하지 못했다. 답변의 필수 내용13개는 충족1·부분4·누락6·오류2였다. 같은 지침의 미세변형은 종료하고, [다음 답변 비교](MEETINGS-FREE-QA-NEXT-DECISION.md)에서 현재3B 모델과 새7B 모델을 같은6개 질문·256토큰·60초 조건으로 비교한다. 아직 새 질문 작성·실제 비교는 시작하지 않았다.

새7B 자산은 첫 실패를 보존한 뒤 새 폴더에서862.985초에 취득했다. 두 파일4.68GB의 전체 해시, 종료와 기존 자료 보존을 확인했고 [내부 설정 검토](MEETINGS-FREE-QA-METADATA-REVIEW.md), 별도 환경과 자산 결속 후보의 검토를 마쳤다. [취득 결과](../experiments/results/meetings-free-qa-acquisition-v2.json)는 실제 로딩이나 답변 품질 검증이 아니다. [출처 계열·질문 해시 목록](MEETINGS-FREE-QA-EXCLUSION-PREPARATION.md)의 준비를 마쳤고 별도 담당자가 새6개 자료를 작성하고 있다. 역사적·의미적 중복을 모두 보장한다고 주장하지 않는다.

요약은 [출력 길이 경계의 순수 검사](MEETINGS-LOCAL-SUMMARY-BOUNDARY-RESULTS.md)를 마쳤으며, 다음은 실제 엔진에서 제약이 지켜지는지 확인하는 일이다. 엔진 도구 취득은 두 번 시간 한도로 실패했다. [두 번째 실패](../experiments/results/meetings-summary-engine-acquisition-v2.json)는595.015초에 멈췄고 LLVM4,406파일까지 추출했다. 실패 폴더를 재사용하지 않으며 파일 수를 환경 통제된 속도 개선으로 해석하지 않는다.

제어 비용 측정에 근거한 [v3 파일 선택·자원 표본 정책](MEETINGS-SUMMARY-ENGINE-V3-PLAN.md)은 초기285개 합성 검사를 통과했지만, 독립 검토가 마지막 실패 기록까지 저장하지 못할 때 남은 파일을 성공으로 수용하는 오류를 발견했다. [외부 종료 기록에 결속하는 수정](MEETINGS-SUMMARY-ENGINE-V3-VERIFICATION.md)은554개 합성 검사와 독립 검토를 통과했다. 최초 결과와 재현은 보존한다.

현재 게시 소스9359a89의 양쪽 필수 CI가 모두 통과했다. [정확 CI 기록](../experiments/results/meetings-summary-engine-v3-ci-v1.json)의 Python5,240통과·21skip, 전체 브라우저158통과와 실제 Java 운영 검증은 모델 품질 증거와 구분한다. 실제 취득 관찰기의 새 준비물도92개 합성 검사·Ruff와 독립 검토를 통과했다. 실행 직전 다른 프로젝트의 로컬 모델이 확인돼 [취득 전 종료](../experiments/results/meetings-summary-engine-v3-prelaunch-v1.json)했다. 관찰기·취득0회이며 다른 서버를 종료하지 않았다. 이 조건이 해소될 때까지 새 QA 자료 준비를 계속한다. 컴파일과 실제 엔진 실행은 아직 시작하지 않았다.

실제 Java 백업·복원12항목과 관련56회귀 검사를 통과했다. 실제 서버·합성 자료의 운영 검증이며 모델 품질·공개 배포·사용자 검수를 대신하지 않는다. [복원 범위와 재현 방법](MEETINGS-RESTORE-VERIFICATION.md)에 앞선 실패도 보존했다.

[통합 질문 기록·피드백 설계](MEETINGS-KNOWLEDGE-HISTORY-PLAN.md)는 모델 품질과 독립적으로 구현한다. 기존 문서 이력을 보존하며 통합 요청의 범위·필터 복원과 현재 권한·revision 검사 후 결과 평가를 연결한다. Java는 실제 SQLite/HTTP 포함255개 통과·기존 선택 검사1개 제외로 확인했다. 화면 로딩 오류와 실제 서버 연결에서 발견한 검색 전환 오류를 수정했다. 최초 전체117통과·2실패를 보존하고 수정 후 관련22개 검사를 통과했다. 독립 검토와 양쪽 필수 CI도 마쳤고 게시 소스의 전체 브라우저120개가 통과했다. [통합 검증](MEETINGS-KNOWLEDGE-HISTORY-VERIFICATION.md)은 실제 Java·모형 응답·실제 AI 품질을 구분한다.

[회의 항목 보정](MEETINGS-MANUAL-CORRECTION-VERIFICATION.md)은 항목 추가/삭제/취소, 정확한 원문 구절 선택, 담당자 작업 편집과 초안 보호를 실제 연결했다. Java273통과·기존skip1, 첫 전체 화면156통과·2실패를 보존했고 기존 두 테스트 조작을 고친 뒤 관련6개가 각각 통과했다. 신규38개 중 실제Java3개이며 나머지는 순수/API모형 검사다. 이후017141a 게시 소스의 전체 브라우저158개와 양쪽 필수CI도 통과했다. 실제 모델의 내용 품질·사용자 검수는 별도로 남는다.

수동 보정 게시 후 운영 CI는 합성 fixture의 옛 고정SHA 때문에 Java 시작 전 실패했다. 기본 경로의 호환성을 확인하고 핀 한 개만 갱신한 뒤 기존 56개 검사와 실제 Java 복원 12개 항목을 통과했다. 수정된017141a의 양쪽 필수 CI와 전체 브라우저158개가 통과했으며 원래 실패는 보존한다. [다음 QA 구현](MEETINGS-FREE-QA-ADAPTER-PLAN.md)은 새 파일 다섯 개에서 두 모델의 정책·자산과 같은 질문·근거·예산을 명시적으로 연결한다. 새 모델의 실제 품질은 아직 미검증이다.

## 남은 순서와 예상 기간

1. 검토된 v3 취득을 새 폴더에서 실행하고 성공 시 컴파일·고정 엔진 검증으로 이어간다. 별도로 새6개 자료와 제외 목록을 고정한 뒤 현재3B/새7B 답변을 같은 조건으로 비교한다. 닫힌 질문으로 튜닝하거나 실패를 덮어쓰지 않는다.
2. 정해진 개발 통과 조건 뒤 격리 validation과 최종 평가를 수행한다. 사용자 검수 상태는 별도로 기록한다.
3. 실제 모델을 포함한 전체 화면, 문서 권한·갱신·삭제, 백업·복원·새 환경 실행을 검증하고 외관·사용성을 확인한다.
4. 기준/개선 비교와 실패 분석을 정리해 시연, 포트폴리오 소개와 면접 설명을 완성한다.

**1차 안정화와 지원용 포트폴리오 정리까지 추가2~4주를 잠정 계획 범위로 둔다.** 실측 개발 속도로 산출한 납기나 보장된 완료일이 아니다. 무료 로컬 모델이 품질 조건을 충족하는지가 가장 큰 변수이며 실제 결과에 따라 다시 판단한다. 코드·검사·준비 완료를 서비스 품질 완성으로 세지 않는다.

녹음·STT·실시간·외부 회의 연동은2차로 남기고 유료 서비스는 사용하지 않는다. 세부 진행과 실제 설정·기여는 [STATUS](STATUS.md), [CONTRIBUTIONS](CONTRIBUTIONS.md), 최종 기준은 [회의 설계](MEETINGS-DESIGN.md)에 기록한다.
