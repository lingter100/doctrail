# 사용자가 보는 현재 진행 상황

기준일: 2026-10-27. **문서·회의 관리 기능은 대부분 구현됐고, 무료 로컬 AI의 내용 품질과 운영 안정성을 검증하는 단계다.** 회의 지능형 관리 1차와 전체 포트폴리오 목표는 아직 미완료다. 완료율을 숫자로 계산할 근거는 없다.

## 지금 시간이 필요한 이유

주요 불확실성은 무료 로컬 모델의 요약·답변 품질이다. 인용 문자열이 원문과 같아도 조건·예외·적용 시점을 빠뜨리거나 요약 문장의 일부만 뒷받침하는 경우가 있다. 모델의 자기검토도 이런 오류를 통과시켜 독립 내용 검토가 필요하다.

최근 실제 비교는 생성2회·자기검토1회 뒤 두 번째 초안의 근거 순서 계약 위반으로 중단됐고 남은6개 비교는 실행하지 않았다. 유효 초안1개의 독립 검토에서는 주장5개 모두 선택 근거로 부분 지원되며 핵심이 부족했다. 이 작은 개발 결과를 전체 모델 정답률로 일반화하지 않고 원래 실패를 유지한다. [결과와 해석](MEETINGS-SUMMARY-MODE-ANALYSIS.md), [독립 판단](../experiments/results/meetings-summary-mode-review-v2.json).

앞선 추가 재작성 후보도 독립 비교에서 초안·수정본 모두 핵심충분0/3이었고, 추가 재작성 시간만 평균29.219초 관측됐다. 개선되지 않은 후보를 서비스 기본값으로 채택하지 않는다. [이전 비교와 한계](MEETINGS-SUMMARY-V3-ANALYSIS.md).

다음 내용 후보는 선택한 상태·시점·조건 문구가 최종 요약에서 사라지지 않게 하는 방식이다. 먼저 새 공개 원문4개에서 같은 길이·근거 한도 안에 충분한 요약을 담을 수 있는지 별도로 판단한다. 자료4개는 독립 수용 검토를 통과했고 향후 평가 제외 목록에 등록했다. 기준을 먼저 고정한 뒤 비교한 결과 flat2/4·새형식1/4만 표현 가능성을 확인해 후보 구현은 보류했다. 미확인을 불가능 증명이나 실제 모델 성능으로 바꾸지 않는다. [선택 이유와 중단 기준](MEETINGS-SUMMARY-CONTENT-NEXT.md).

실제 Java 백업·복원은12항목을 통과했다. 회의 편집·작업·결정 연결을 보존하고 복원 전 쿠키 거부, 재로그인, 권한과 원문 검색을 확인했다. 두 초기 실패를 보존한 뒤 도구를 보완했고 최종56회귀와 독립 검토를 통과했다. 실제 서버와 합성 자료의 운영 검증이며 모델 품질·공개 배포·사용자 검수를 대신하지 않는다. [복원 범위와 재현 방법](MEETINGS-RESTORE-VERIFICATION.md).

새 무료 모델의 첫 시작 메모리 실패와 후속 입력 한도 초과를 보존했다. 입력 전송 형식과 별도 메모리 정책을 적용한 [최근 실제 비교](MEETINGS-LOCAL-RESOURCE-RESULTS.md)는 요약4개·답변4개를 생성했지만, 출력한도4건·JSON형식4건으로 모두 거부됐다. 구조 검사 수용은0/8이며 의미 정확도0%라는 뜻은 아니다. 원본 응답은 고치거나 재사용하지 않는다.

[생성 형식 개선](MEETINGS-LOCAL-FORMAT-NEXT.md)은 기존 모델·원문·질문·품질·시간 예산을 유지하면서 응답 JSON 문법만 적용하는 후보다. 현재 코드와 관련 합성 검사147개·Ruff, 별도 독립 코드 검토를 통과했다. 새 코드의 필수 CI, 실제 문법 엔진 실행, 결과의 의미 검토는 아직 남아 있다. 모형 응답 검사 통과를 실제 모델 품질 개선으로 세지 않는다.

## 남은 순서와 예상 기간

1. 최근 출력 형식 실패를 보존하고 생성 문법 후보의 코드 검토·필수 CI를 마친 뒤, 새 등록으로 실제 요약·답변과 근거 의미를 검증한다. 구조 통과와 내용 품질을 각각 판단한다.
2. 정해진 개발 통과 조건 뒤 격리 validation과 최종 평가를 수행한다. 사용자 검수 상태는 별도로 기록한다.
3. 실제 모델을 포함한 전체 화면, 문서 권한·갱신·삭제, 백업·복원·새 환경 실행을 검증하고 외관·사용성을 확인한다.
4. 기준/개선 비교와 실패 분석을 정리해 시연, 포트폴리오 소개와 면접 설명을 완성한다.

**1차 안정화와 지원용 포트폴리오 정리까지 추가2~4주를 잠정 계획 범위로 둔다.** 실측 개발 속도로 산출한 납기나 보장된 완료일이 아니다. 무료 로컬 모델이 품질 조건을 충족하는지가 가장 큰 변수이며 실제 결과에 따라 다시 판단한다. 코드·검사·준비 완료를 서비스 품질 완성으로 세지 않는다.

녹음·STT·실시간·외부 회의 연동은2차로 남기고 유료 서비스는 사용하지 않는다. 세부 진행과 실제 설정·기여는 [STATUS](STATUS.md), [CONTRIBUTIONS](CONTRIBUTIONS.md), 최종 기준은 [회의 설계](MEETINGS-DESIGN.md)에 기록한다.
