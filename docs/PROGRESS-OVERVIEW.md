## 이미 얻은 AI 실험 근거

원래 dev 평가의 필수 근거 회수는 BM25 30/59, 기존 혼합+리랭커 36/59, 후보 선택 개선 후 37/59였다. 별도 학습 저장본 비교에서는 E5 상위5 회수가 29/59에서37/59로 바뀌었지만, 다중 문서 질문은1/7에서0/7로 나빠졌다. 사용자 검수0·최종 test 잠금·개발 평가라는 한계를 유지한다. 숫자는 [M3 분석](M3-ANALYSIS.md), [후보 개선 분석](M3-CANDIDATE-ANALYSIS.md), [M4 분석](M4-MAIN-DEV-ANALYSIS.md)의 저장된 실측이며 이번에 재실행하지 않았다.

실제 자연어 답변은 인용 문자열이 맞아도 내용이 틀리거나 질문 일부를 놓쳤다. C3의 독립 최종 답변 판정은2/6이었고 이후 경로도 시간 또는 입력 조건에서 종료됐다. 현재 C7은 새로운 공개 자료가 원문 전체·의미 요구·입력 제한을 함께 만족하는지 확인하는 단계이며 모델 품질 실행으로 넘어가지 않았다. 실패를 성공으로 바꾸거나 자료를 줄여 같은 실험을 구제하지 않는다.

## 남은 순서와 일정의 불확실성

1. 제한된 공개 자료 가능성 검토를 완료한다. 두 역할이 최대12개 원문 슬롯 안에서 판단하며 범위를 무한히 늘리지 않는다. 결과는 자료 수용이나 모델 성공과 다르다.
2. 계속할 근거가 있으면 기존 C7 준비·독립 검토·고정 품질 평가로 이어간다. 근거가 없으면 해당 탐색 경로를 종료하고 engineering 정책을 별도로 판단한다. 전체 프로젝트를 완료했다고 처리하지 않는다.
3. 검증된 AI 경로를 실제 서비스의 전체 사용자 흐름에서 확인하고 화면·복구·운영의 남은 조건을 정리한다.
4. 최종 시연·실험 비교·실패 분석·면접 설명을 묶고 사용자 검수와 AI 검토를 구분한다.

전체 완료일이나 의미 있는 완료 퍼센트를 산출할 근거는 아직 없다. 남은 작업은 단순 화면 수정의 양보다 무료 로컬 모델의 품질 관문 통과 여부에 좌우된다. “며칠 후 완료”나 “거의 완료”를 약속하지 않는다. 현재 제한된 자료 검토 결과를 다음 일정 판단 지점으로 삼는다. 종료 시한 없이 같은 준비와 실험을 반복하는 것을 진행 성과로 세지 않는다.

지금까지 검증 도구·실험 계약·실패 보존에 상당한 작업이 들어갔다. 이것은 재현성과 정직한 보고에 필요하지만 사용자에게 보이는 기능 완성이나 모델 품질 개선과 같은 성과는 아니다. 기능·품질·운영·발표 준비의 상태를 위 표처럼 따로 보고한다.

녹음·STT·실시간·외부 회의 연동은 2차 범위로 계속 제외한다. 유료 서비스는 사용하지 않으며 공개 서비스 배포는 별도 승인 사항이다.
