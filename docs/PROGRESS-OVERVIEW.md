# 사용자가 보는 현재 진행 상황

기준일: 2026-10-31. **문서·회의 관리와 화면 연결은 구현했으며, 무료 로컬 AI의 답변·요약 품질과 최종 운영 검증이 남아 있다.** 회의 지능형 관리 1차와 전체 포트폴리오 목표는 진행 중이다. 완료율을 숫자로 계산할 근거는 없다.

사용자가 체감하는 핵심 미완료는 “회의를 넣으면 믿을 만한 요약과 답변이 나오는가”다. 관리 기능과 많은 회귀 검사가 있어도 이 부분을 대체하지 못한다. 로컬 모델의 내용 실패와 실행 환경 오류를 해결하는 과정에서 실행 통제·검토 절차도 지나치게 커졌다. 닫힌6개 QA 비교는 두 모델 모두 독립 AI 내용 수용0/6으로 종료했고 재튜닝하지 않는다. 현재 오프라인 도구 검증이 실제 정상 종료해 컴파일·문법 실행으로 이어갈 수 있는 근거를 얻었지만, 실제 생성 요약과 QA 내용 품질은 별도 미완료다.

## 기능별 상태

| 영역 | 확인한 범위 | 완료까지 남은 일 |
| --- | --- | --- |
| 문서 서비스 | Java/React 로그인·작업공간·권한·등록·수정·삭제·재처리·검색·원문 근거·기록·피드백 | 실제 모델을 포함한 최종 회귀, 새 환경 실행과 운영·복구 확인 |
| 검색 모델 | BM25·임베딩·혼합·리랭커 비교, 도메인 임베딩 미세조정 실험과 서비스 연결 | 격리 최종 평가, 사용자 검수, 학습 모델의 기본 채택 판단 |
| 회의 관리 | 텍스트 등록·로컬 AI 분석 호출·결정·담당 작업·원문 근거, 명시적 결정 변경 연결, 항목과 담당자 편집 | 자동 요약·작업 분류 품질 개선, 실제 자료와 실제 모델의 최종 검증 |
| 자연어 답변 | 실제 로컬 호출·인용 검증·답변 보류·오류 복구 | 충분한 답변과 적절한 보류의 독립 품질 평가, 응답 시간과 운영 수용 |
| 화면·운영 | 회의·작업·통합 검색 화면, 데스크톱·좁은 화면 흐름, 원문 이동·초점·실패 안내, 백업·복원 | 실제 모델의 최종 화면 흐름, 외관·사용성 사용자 검수, 새 환경·부하·장애 검증 |
| 포트폴리오 | 데이터·설계·실험·실패·실행 방법, 소개·면접 초안 | 최종 시연·비교 결과와 사용자 직접 결정·검수 기록 |

화면 완성도도 완료 기준이다. 실제 Java와 합성 모델 응답을 연결한 화면 검사는 실제 AI의 내용 품질이나 사용자 검수를 대신하지 않는다.

[오프라인 도구 준비](../experiments/results/meetings-summary-offline-acquisition-v1.json)는 실제 정상 종료했다. 한글 경로와 임시 파일 삭제 경합을 보정했지만, [v4 빌드](../experiments/results/meetings-summary-compat-build-v4.json)에서 Ninja의 Windows 셸 명령이 실행 제한에 걸렸다. 확인된 빌드 도구·작업 폴더에 한정한 후속 정책의 구현·집중 검사·독립 검토·게시와 필수 CI를 마쳤다. 새 실제 빌드가 남아 있다. 엔진 컴파일·문법 실행·새 요약 품질은 아직 미완료이며 실패 원본은 보존한다.

## 지금 해결하는 문제

[최신 QA 비교](MEETINGS-FREE-QA-PAIRED-V3-RESULTS.md)는 같은 6개에서 기준 3B와 후보 7B 모두 내용 수용 0/6으로 종료됐다. 입력 한도 초과·출력 잘림뿐 아니라 필수 내용 누락, 선택 근거와 주장의 불일치, 답변 보류 실패가 남았다. 인용 문자열 일치와 충분한 답변은 다르다. 작은 개발 비교이므로 일반 정답률로 확대하지 않으며 같은 질문 재튜닝·자동 다음 모델 탐색은 하지 않는다.

요약의 [문법 엔진 검증](MEETINGS-LOCAL-SUMMARY-ENGINE-VALIDATION-PLAN.md)은 빌드 문제를 해결하는 단계다. 원본 도구를 보존하는 [Windows 경로 호환·임시 파일 검사 수정](MEETINGS-SUMMARY-PATH-COMPATIBILITY.md)을 구현했다. 다음 실제 빌드가 통과해도 문법 제약의 동작과 생성 요약의 내용 품질을 따로 검증해야 한다.

새 공개 개발 자료의 [실제 Java QA](../experiments/results/meetings-qa-service-development-v1.json)는 첫 검색 후 답변 형식 오류로 실패했다. 독립 내용 검토에서도 제안을 확정으로 오해하고 다른 규정을 인용한 오류를 확인했다. 검색된 문서3개 안에 필요한 출범 규정이 빠져 있어, [키워드·임베딩·혼합 검색6회](MEETINGS-QA-RETRIEVAL-DEVELOPMENT.md)를 먼저 비교한다. 두 질문은 공개 개발 자료이며 잠긴 최종 평가가 아니다.

## 현재 검증 근거

- 새5d164212의 [필수 CI](../experiments/results/meetings-startup-source-ci-v1.json)는 단위 검사5,848개·브라우저162개·Java/웹 검사 통과와 별개로, 과거 실험의 고정 파일 충돌 때문에 실패로 종료했다. 원본 복원과 [개발 진입점 분리](../experiments/results/meetings-retrieval-diagnostic-entrypoint-v1.json)는70개 가상 검사·고정 해시46/46·독립 검토를 마쳤으며 새 CI가 남았다. 실패한 CI를 통과로 바꾸지 않는다.
- 게시 `724eb907`의 [필수 CI](../experiments/results/meetings-ninja-ui-ci-v1.json): push·PR의 backend/web/java-service 모두 통과. 각각 Python5,809개 통과·21개 제외, 브라우저162개 통과·실패0과 Java/운영/프런트 빌드를 확인했다. 실제 모델 의미 품질을 증명하는 검사는 아니다.
- 분석 실패를 AI 초안/추출0개처럼 표현하는 안내 문제와 한국어 조사 오류를 수정했다. 타입 검사·웹 빌드·Java 패키징과 [집중 브라우저6개](../experiments/results/meetings-ui-analysis-visibility-v1.json),1440/390px 실제 실패 화면 확인을 마쳤다. 이 수정은 게시 후 필수 CI도 통과했으며 사용자 직접 검수로 계산하지 않는다.
- [실제 회의 관리 흐름](MEETINGS-MANUAL-CORRECTION-VERIFICATION.md), [백업·복원](MEETINGS-RESTORE-VERIFICATION.md), [실제 QA 실패와 독립 AI 판정](MEETINGS-FREE-QA-PAIRED-V3-RESULTS.md)은 서로 다른 증거다. CI 통과가 실제 AI 품질 수용을 뜻하지 않는다.
- 사용자 직접 검수·공개 서비스 배포는 완료하지 않았다. 실패 후보는 기본 모델로 채택하지 않았다.

## 다음 순서

1. 실제 비교는 종료했다. 모든 유효 출력의 독립 의미 판정을 마쳤고 한도 거절과 내용 오류를 분리했다. 두 모델 모두 원래6/6 선택 조건에 미달했으므로 이 비교를 닫고 자동 다음 모델·프롬프트 탐색이나 같은 질문 재튜닝을 하지 않는다.
2. 무료 로컬 요약·답변이 개발 수용 조건을 충족하도록 진행하고, 그 뒤 격리 validation과 최종 평가를 수행한다. 최종 평가 질문으로 튜닝하지 않는다.
3. 실제 모델을 포함한 전체 화면·권한·문서 갱신/삭제·백업/복원·새 환경 실행을 확인한다. 외관·사용성 사용자 검수는 별도로 남긴다.
4. 비교·실패·한계를 정리해 최종 시연, 소개와 면접 설명을 완성한다.

기존 추가 2~4주는 잠정 계획 범위였으며 현재 보장된 완료일이 아니다. 관리 기능의 개수나 회귀 검사 수로 남은 시간을 계산할 수 없다. 가장 큰 변수는 무료 로컬 모델의 내용 품질이다. 다음 완료 판단은 ① 요약 도구의 실제 취득·컴파일·문법 검사 ② 실제 요약·답변의 독립 품질 수용 ③ 실제 모델을 포함한 전체 흐름·운영·시연 검증으로 나눠 보고한다. 첫 단계 성공도 전체 AI 기능 완성을 뜻하지 않는다.

녹음·STT·실시간·외부 회의 연동은 1차 완료 후다. 유료 서비스는 사용하지 않으며 공개 서비스 배포는 별도 승인·검증 사항이다. 세부 기록은 [STATUS](STATUS.md), AI와 사용자 역할은 [CONTRIBUTIONS](CONTRIBUTIONS.md), 완료 기준은 [회의 설계](MEETINGS-DESIGN.md)에 남긴다.
