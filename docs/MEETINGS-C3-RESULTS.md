## 문제와 방법

앞선 C2는 원문 인용이 정확해도 필요한 정보를 빠뜨리거나 인용이 주장을 뒷받침하지 못했다. C3는 질문의 요구사항과 근거를 먼저 계획하고, 모든 요구사항이 지지된다고 판단할 때만 별도 단계에서 자연어 답변을 만든다. 한 요청에 최대 두 번의 로컬 추론과 공유 90초 기한을 적용한다. 실제로 실행되는 코드·자료·평가 규칙을 먼저 고정했다.

이 실험은 고정 문맥에서 답변 생성만 평가한다. 검색을 포함한 Java 서비스 전체 지연이나 일반 사용자의 만족도 측정이 아니다. 기존 실험과 다른 새 문항을 사용하므로 점수를 직접 비교해 개선률을 계산하지 않는다.
