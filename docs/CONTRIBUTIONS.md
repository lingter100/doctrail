# 기여와 직접 검증 기록

## 사용자 직접 결정

2026-10-12: AI Engineer / Applied AI Engineer 신입 지원 목적, 개인 프로젝트, 문서 서비스 클론과 검색 모델 개선, 재현 가능한 실험·학습·배포 목표를 정의했다. 국내 채용과 한국어·영어 혼합 문서를 선택했다. 제품명과 구체 도메인·일반 구현 선택을 AI에게 위임했다. 본인 GitHub 계정의 공개 저장소·커밋 이력과 Git 규칙을 요청했다. 유료 사용·서비스 외부 배포 승인 절차를 정했다.

## AI가 수행한 범위

환경·도구 확인, 경쟁 서비스·채용 요구 조사, 도메인 구체화, 구조·데이터·평가 설계, 코드·테스트·문서 작성과 자동 검증을 지원한다. 실제 완료 결과는 STATUS에 기록한다. 이 기록은 사용자가 혼자 모든 코드를 직접 작성했다는 주장이 아니다.

## 사용자 검증 상태

아직 사용자의 UI 시연, 평가 질문 검수, 모델 결과 승인, 면접 답변 숙지 확인을 기록하지 않았다. 자동 테스트나 AI 검토를 사용자 검수로 바꾸어 기록하지 않는다.

## M1 실제 수행 결과

AI가 FastAPI/SQLite·TypeScript 구현, 테스트 36개, 데이터 수집·정제·평가·분할 검사·복구 도구와 문서를 작성했다. 브라우저 시연과 공개 문서 8개·점검 질문 12개 평가를 수행했다. 별도 구현 에이전트의 검토에서 가공 입력 검증과 근거 분할 검증 누락을 발견해 수정했다. 질의응답 모델이나 미세조정은 수행하지 않았다.

브라우저의 `로컬 검증` 계정과 그 계정이 남긴 검색·피드백은 AI가 실제 서비스를 점검한 테스트 데이터다. 사용자 조사나 사람이 제공한 검색 만족도 결과로 집계하지 않는다. 저장소 커밋의 계정 표시는 코드 직접 작성 비율이나 사용자 검수의 증거가 아니다.

## M2 실제 수행 결과

사용자는 제안한 방향대로 진행하도록 위임했다. AI가 313문서 코퍼스와 240질문 후보, 검증·검수 도구·개발 평가·HTTP 측정·실패 분석을 작성하고 실행했다. 부모 에이전트가 통합, 원문 대조, 검증기 보강, 리비전 도구, HTTP 측정 도구와 Windows 파일 정리 수정을 수행했다. 별도 AI가 dev 다중 문서 후보 8개(053~060)의 20개 구간을 원문과 대조했고 055의 두 문서 필요성에 이의를 제기했다. 이 후보는 검색 실행 전에 dev v1.1에서만 제외했다. 나머지 7개가 참조 답안을 뒷받침한다는 AI 검토는 전체 질문의 의미적 정확성이나 사람 검수를 증명하지 않는다.

질문 초안·지침 해시·허용 문서·실제 지정한 모델은 `data/evaluation/generation/`에 남겼다. AI 생성 재호출은 재현하지 않았으며 저장된 초안의 컴파일·검증을 재현했다. 검수 HTML에서 질문 이동과 빈 판단 제출 거부를 AI가 점검했지만 검수자 이름·판단을 입력하거나 사용자 승인을 만들지 않았다. 실제 사용자 검수 0개, 실제 사용자 피드백 연구 0명이다.

M2에서도 서비스 내부 모델은 BM25다. 개발 보조 모델 사용량은 서비스 API 요청당 비용에 합산하지 않았다. 서비스의 외부 모델 API 호출은 0건이며 로컬 전력·장비 비용과 개발 보조 구독 비용의 배분은 측정하지 않았다.
