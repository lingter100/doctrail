# 새 QA 비교의 실행 전 호출 오류

2026-10-29. **AI 실행자의 인자 전달 오류로 CLI가 시작되기 전에 중단됐다. 모델 성능 결과는 없다.** 실행 소스는 `7ca36980555814bc129a71077a739bd21967c3fe`다. [기계 판독 기록](../experiments/results/meetings-free-qa-neutral-prelaunch-v2.json).

같은 봉인 입력과 모델 설정을 유지한 [후보 준비](../experiments/results/meetings-free-qa-paired-v2-preparation-v1.json)는 독립 검토를 통과했다. 계약·신뢰·중립 등록3파일을 설치했고 공식 메타데이터 확인1회는 종료0·1.5402392초였다. 이것은 실제 모델 실행 증거가 아니다.

새 충돌 확인은 통과했지만 실행자가 PowerShell의 `ArgvJson`에 JSON 파일 경로 대신 JSON 문자열을 전달했다. 원본 실행기는 `Resolve-Path`에서 오류 시 종료하도록 되어 있고, 이 위치는 `Start-Process`보다 앞선다. 실제 도구 종료1과 observer·CLI 출력·두 예약 파일 부재를 대조했다. 따라서 CLI 호출0·once 미소비로 분류했다. GPU 메모리나 모델 준비 실패로 해석하지 않는다.

같은 관찰 세션은 종료1로 닫혔다. 엄격한 종료 확인도 종료1·증거 공백13개이며 이 결과를 그대로 보존한다. 관찰한 신원이 없으므로 소유 프로세스 부재는 `UNKNOWN_NO_CAPTURE`다. 파일 보존은 별개로211개 해시·74개 자산 신원이 모두 일치했고 부모가55개 직접 참조와 전체 목록을 확인했다. 기록 보존 성공을 실행 성공으로 바꾸지 않는다.

이번 실행 배정은 재시도하지 않았다. 후속 작업은 원래 실패 폴더를 유지하고 올바른 파일 경로를 고정한 새 외부 호출을 검토하는 것이다. 아직 모델 호출이 없었으므로 기존 계약·봉인 자료·모델 설정·미소비 once를 바꿀 근거는 없다. 새 배정과 새 충돌·자원 확인을 거친 뒤 실제 중립 생성1회를 진행한다. 과거 비교v1 실패의 정확한 원인과 품질 미완료 상태도 유지한다.
