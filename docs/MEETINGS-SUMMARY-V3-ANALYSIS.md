# 원문 대조 재작성은 왜 채택하지 않았나

2026-10-23. 무료 로컬 모델을 이용한 회의 요약 개발 비교다. 실제 모델을 실행했지만 자료는 기존에 노출된 합성 회의이며, 평가는 재사용한 기준에 따른 독립 AI 검토다. 사용자 검수·격리 최종 평가·실제 조직 품질을 대신하지 않는다.

## 해결하려던 문제와 선택

기존 요약은 원문에 있는 구절을 인용해도 조건·예외·적용 시점 같은 핵심을 빠뜨렸고, 한 문장의 일부만 인용으로 뒷받침하는 경우가 있었다. 같은 모델의 자동검토도 이를 충분하다고 표시했다.

이번 후보는 기존 초안을 전체 원문과 다시 대조해 한 번 재작성하고, 수정본만 마지막 근거 검토에 보냈다. 문장 수정뿐 아니라 빠진 핵심 추가·인용 보충·문장 분할을 허용했다. 인용만 교체하는 대안은 내용 누락을 해결하기 어렵고, 검토를 엄격하게만 하는 대안은 충분한 요약을 만들어 주지 못한다고 판단했다. 모델·분류·기존 서비스 계약은 유지했다. [사전 설계](MEETINGS-SUMMARY-CLAIM-ALIGNMENT-PLAN.md).

## 비교 방법

같은 요청의 초안과 수정본을 모두 보존했다. 판정자는 단계 이름을 받기 전에 여섯 후보를 각각 평가해 판단을 고정했다. 그 뒤 단계·쌍 매핑만 받아 이미 고정된 판단을 대조했다. 모델 자기검토는 두 판단이 모두 고정된 다음에 공개했다.

원문 전체의 지원, 선택한 인용의 지원, 핵심 정보의 충분성, 인용 좌표를 별도로 평가했다. 같은 원문 ID로 후보 묶음을 추정할 수 있었고 과거 집계에 노출돼 있었으므로 완전한 맹검은 아니다. 부모 에이전트는 내용에 새 점수를 주지 않고 해시·산술·문장과 인용의 기계적 변화만 확인했다.

전체18주장 중 문장3개와 다른 주장1개의 인용이 바뀌었다. 한 쌍은 완전히 같았다. 고정된 지원·핵심 상태의 회복과 퇴보는 모두0이었다. 초안71개·수정본70개 인용의 좌표는 모두 정확했지만 의미 품질은 통과하지 못했다. 단순한 표현 변화나 인용 삭제를 개선으로 세지 않았다. [독립 쌍 결과](../experiments/results/meetings-grounded-summary-review-v3.json).

재작성 호출의 전송 관측은 평균29.219초였다. 전체 분석 관측은88.250/101.328/107.984초였으며 모든 모델 호출이EOS로 끝났다. 각 구간은 겹칠 수 있으므로 더해서 사용자 응답 시간으로 부르지 않는다. 이 표본에서는 추가 시간을 사용했어도 고정된 품질 상태가 개선되지 않았다. [성능·토큰과 측정 구간](../experiments/results/meetings-grounded-summary-performance-v3.json).

서비스 전체 실행은 두 요약의 저장·원문 이동 뒤 세 번째 최종검토 거부로 종료됐다. 예정한 네 번째 회의와 질문6건은 미실행이다. 실제 CLI/Node exit1과 최초 실패는 유지한다. 정상 프로세스 정리와 자동 검사 통과가 전체 실행 실패를 성공으로 바꾸지는 않는다. [실행 결과](../experiments/results/meetings-grounded-summary-development-v3.json).

## 자기검토에서 배운 점

같은 모델은18주장 중16개를supported로 표시했다. 그16개 중 고정된 선택인용 판단과supported가 일치한 것은10개였고, 나머지는partial5개·ambiguous1개였다. 모델은 세 요약 모두 핵심이 충분하다고 표시했지만 독립 판단에서는 모두 부족했다. 서로 다른 범주를 이진 정답/오답으로 강제 변환하거나 모델의 내부 실패 원인을 추측하지 않았다. [자기검토 대조](../experiments/results/meetings-grounded-summary-self-review-v3.json).

따라서 이번 재작성은 기본 동작으로 채택하지 않는다. 정확한 인용 위치, 모델 자기검토, 독립 내용 판단, 실제 사용자 수용을 서로 다른 증거로 다뤄야 한다. 다음 후보도 기존 실패를 다시 실행해 통과시키는 방식이 아니라, 별도 사전 계획과 자료·조건으로 비교한다.

## 면접에서 설명할 요점과 직접 확인할 부분

- **문제:** 인용 문자열이 맞아도 요약이 핵심을 빠뜨리거나 인용보다 많은 내용을 말할 수 있다.
- **검증:** 같은 요청의 초안과 수정본을 따로 잠가 비교해 추가 호출의 효과를 구분했다. 평가가 끝난 뒤 자기검토 값을 공개했다.
- **결과:** 표현은 일부 바뀌었지만 고정된 내용 품질은 개선되지 않았고 약29초의 추가 호출이 생겨 채택하지 않았다.
- **한계:** 세 회의의 노출된 합성 자료와 AI 판단이다. 사람의 정답 판정이나 일반화 성능으로 말할 수 없다.
- **사용자가 확인할 부분:** 최종 시연에서 요약의 핵심 보존, 문장별 근거의 충분성, 한국어 표현과 대기 경험을 직접 확인해야 한다. 현재 사용자 검수는0이다.

설계·구현·실행·자동 검증·독립 AI 판단과 문서 작성은 AI가 수행했다. 무료·로컬 범위와 서비스 기술 스택·기능 목표는 사용자가 지정했다. 사용자 검수나 사람의 코드 승인을 AI가 대신 만들어 기록하지 않았다.
