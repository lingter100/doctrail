# 새 QA 비교 자료의 제외 목록 준비

2026-10-28 · 메타데이터 준비 검증 · 새 질문과 실제 모델 평가는 별도

새 모델을 평가할 때 이미 사용한 질문이나 예약된 자료를 다시 고르면 결과를 과대평가할 수 있다. 기존 평가 본문을 새 작성자에게 보여주지 않으면서 출처 계열·문서 식별자·질문 해시를 비교하도록 두 목록을 준비했다.

## 실제 확인한 범위

| 목록 | 확인한 결과 | 숫자의 의미 |
| --- | --- | --- |
| 출처 메타데이터 | 입력52개, 행5,908개, 계열 문자열·별칭287개, 저장소 선택자30개, 게시자 선택자1개 | 문서 수가 아니다. 원본·예약·거부·중복 기록을 함께 보존했다. |
| 질문 기계 투영 | 파일51개, 원본·수정본 기록1,118건, 고유 질문 해시516개, 식별자525개 | 질문 내용을 모델에 출력하지 않고 고정된 질문 필드만 UTF-8 SHA-256으로 변환했다. |
| 질문 중복 | 중복 해시 그룹405개, 첫 항목 이후 반복602건 | 반복을 지우거나 새 사례로 세지 않고 원래 파일·버전에 연결했다. |
| 결속 검증 | 질문 준비의 입력192개 불변, 선언된 참조 해시90건 일치, 재생성 바이트 동일 | 본문 내용의 품질이나 의미적 독립성을 판정한 결과가 아니다. |

질문 해시는 실행기의 `SHA256(question.encode("utf-8"))`와 같다. 공백 정규화나 번역 비교를 새로 추가하지 않았다. 출처의 원시·정규화·파일 해시는 종류를 구분한다. M5B의15개 계열·별칭은 문서별 결속이 부족한 경우에도 전체를 보수적으로 제외한다.

부모는 출처 단계56참조와 질문 단계205참조를 다시 확인했다. AI 검토이며 사용자 검수는0이다. 새 질문 작성자, 사전 검토자, 실행자와 최종 판정자는 별도 역할로 배정한다. 부모와 구현자는 질문·기준·답변 의미를 읽지 않는다.

## 실패와 제한

초기 질문 투영은 혼합 작업 배열에서 질문이 없는 분석 항목을 만나 결과 생성 전에 실패했다. 최초 목록과 실패를 보존하고, 명시된 문자열 질문 필드의 존재만 선택하는 새 목록으로 수정했다. 질문 내용이나 결과를 기준으로 사례를 고르지 않았고 예상 질문 수와 원본 자료는 변경하지 않았다.

이 목록은 기록으로 확인할 수 있는 유한한 범위다. 기록되지 않은 과거 노출이나 번역·의미 중복 전체를 보장하지 않는다. 불명확한 계열을 새 자료라고 추정하지 않으며 기존 거부·예약 계열과 조상 저장소도 제외한다. 부족한 역사적 정규화 해시를 만들려고 보호된 본문을 새로 읽지 않았다.

준비 목록은 실행 승인이나 신뢰 등록이 아니다. 실제 실행기에 연결할 후보 목록과 출처 규칙을 만든 뒤 새6개의 출처·충분성·근거·보류 기준을 별도로 사전 검토한다. 새로운 모델 응답은 아직 생성하지 않았다. [비교 결정](MEETINGS-FREE-QA-NEXT-DECISION.md)의4개 답변 가능·2개 보류와 고정 예산을 유지한다.

재현 기록은 아래 결과의 해시로 연결된다. 보호된 입력과 세부 식별자 목록은 로컬에 보존하며 공개 저장소에는 안전한 집계만 게시한다. 이 공개 집계만으로 비공개 원본까지 완전히 재현할 수 있다고 주장하지 않는다.
