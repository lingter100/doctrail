**분량 계획 지침을 추가했지만 요약의 형식 수용은0/4로 유지됐다.** 같은 실행의 답변4개는 형식을 통과했으나 별도 AI 내용 수용도0/4였다. 이번 후보는 서비스에 채택하지 않는다. [실측·별도 내용 평가](../experiments/results/meetings-local-summary-control-actual-v1.json), [기존 v5 결과](MEETINGS-LOCAL-FORMAT-RESULTS.md)를 각각 보존한다.

## 비교한 방법

[사전 설계](MEETINGS-LOCAL-SUMMARY-CONTROL-NEXT.md)의 정확한5줄 지침을 요약 system에만 추가했다. 160자/총960자는 작성 목표이며 기존 hard240/1200·내용/근거 기준을 낮추지 않았다. 모델·원문4·질문4·순서·문법·시간/자원/토큰 예산은 동일하다. QA와 필수 review 요청은 바꾸지 않았다.

코드의188합성검사·Ruff·별도 정적 검토와 [정확 소스 CI](../experiments/results/meetings-local-summary-control-source-ci-v1.json)를 통과한 뒤 새 등록으로 실제1회 실행했다. 이 코드 검증과 실제 모델 품질은 별개의 결과다.

## 실패 원인에서 확인한 것

저장된 요약 요청4개의 system은 고정5줄·기존 prompt·compact 범례의 정확한 해시와 일치했다. 따라서 지침이 기록된 요청에서 빠진 문제는 아니다. 전송 확인은 모델이 그 지침을 이해하거나 준수했다는 증거와 다르다.

3개는 실제768토큰 상한에서 JSON 문자열이 끝나지 않았다. EOS1개는JSON이 완결됐지만 두 번째 주장243자가 기존240자 한도를 먼저 위반했다. 뒤의254/248자 문장과 총1239자도 한도를 넘었지만 첫 오류를 그 결과로 바꾸지 않았다. soft160/960은 오류 기준으로 사용하지 않았다.

기존 grammar의 문자열 규칙은JSON형식을 제어할 뿐 decoded 본문의 개별/합계 문자 수나 토큰 완결을 보장하지 않는다. 실제 입력 토큰 범위는2324~3184에서2507~3367로 늘었으나4096입력 제한은 넘지 않았다. 문장을 자르거나 부분JSON을 수리해 수용하지 않았다. 유효 요약이 없으므로 의미 점수를 부여하지 않았다.

## 답변의 별도 내용 평가

사전 포함 규칙에 맞는 현재 답변4개를 모두 새 익명 패킷으로 전달했고, 판정자는 현재 원문·질문·출력을 직접 판단한 뒤 개별 해시를 먼저 잠갔다. 이전 v5판정 파일을 복사하거나 수정하지 않았지만 과거 내용과 자동 문맥 노출이 남아 있어 완전 맹검으로 주장하지 않는다.

인용11개는 원문과 같았다. 그러나 선택 근거의 주장 전체 지지는 완전0·부분3·미지지1, 원문 전체 기준은 완전1·부분2·미지지1이었다. 필수13요소는 충족1·부분7·누락4·오류1로 판정됐고 답변4개 모두 충분하지 않았다. 사람 검수는0이다. 이번 개입은QA요청을 바꾸지 않았으므로 이 결과를 새 QA개선 시험으로 표현하지 않는다.

## 운영과 보존

공식CLI1회/exit1, 관찰 도구exit0을 구분한다. 내부 실행88.204초, CLI전체89.25초였다. fixed8생성 일정은 끝났지만 품질 수용은 실패다. 시작 가용RAM9,657,360,384B, sampled native RSS최대3,000,971,264B, host RAM최소6,764,367,872B, 장치 전체VRAM최대3163MiB를 관측했다. 순간 최대치·독점 사용량·메모리 예약은 아니다.

정리0.390초, 소유20신원의 부재와 잠금3개 해제를 확인했다. 부모는 원본66파일·내부63연결·고정512참조·코드60·자산62상태를 대조했다. 모델의 원문 출력·판정 설명은 부모가 읽지 않고 해시와 안전 집계만 확인했다. 이전실패·동결자료·이번소비실행을 보존했다.

유료 생성API·GPU임대·클라우드는 사용하지 않았다. 전력·기기 감가비용은 측정하지 않았으며 총비용0으로 주장하지 않는다. 실제 서비스 검색/ACL·UI·공개배포 완료를 이 전체원문 생성 실험으로 대신하지 않는다.

## 다음 작업

[QA 전용 지침 후보](MEETINGS-LOCAL-QA-CONTROL-NEXT.md)는 질문 전체의 요구와 주장별 근거 선택을 다루며, 이번 v6판정 종료 후 코드 변경을 시작한다. 같은 요약 정책을 기준선으로 두고 QA지침 하나만 추가한다. 수용0/4가 유지되면 같은 지침의 미세변형 반복을 멈춘다. 아직 구현·실제효과는 없다.

요약은 정확한지침전송을확인했어도길이규칙을충족하지못했다. 또다른문구수정으로성공을가정하지않고, 원래허용내용/하드기준을줄이지않는출력제약·예산·생성방식의대안을별도로검토한다. 판정기준을완화하거나원본을고치지않으며추가실험은새계획/등록으로분리한다.

최종 목표는 충분하고 근거 있는 요약·답변, 실제 검색 문맥/권한/문서 갱신, 화면·사용성·운영 검증이다. 이번 실패를 끝으로 목표를 완료하거나 축소하지 않는다. 진행은 [STATUS](STATUS.md), 사용자가 보는 범위는 [진행표](PROGRESS-OVERVIEW.md)에 기록한다.
