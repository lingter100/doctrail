# 결정 기록

## 2026-10-12 시작

- 제품명 DocTrail. 소규모 개발 조직의 온보딩·운영 문서 탐색을 대상으로 한다. 한·영 공개 기술 문서 확보와 권한·개정 실험을 연결하기 쉽다.
- 첫 실행 흐름은 FastAPI + SQLite + TypeScript 웹 UI + BM25. 외부 API 비용 없이 등록·권한·근거의 정확성을 검증한다. 이후 모델 비교 전까지 BM25를 고정 기준선으로 유지한다.
- 대안 PostgreSQL/pgvector는 M1에서 운영 복잡도를 늘리므로 보류한다. 1,000문서 데이터 확장·임베딩 검색 단계에서 이전 필요성을 실제 지연·처리량과 함께 판단한다.
- 단순 전체 말뭉치 검색 후 권한 필터 방식은 배제한다. 사용자별 허용 문서를 후보 생성 및 점수 계산 전 제한한다.
- 로컬 GPU는 RTX 4050 6GB. 소형 리랭커 학습 후보를 우선 검토하되 현재 미학습이며 실제 데이터와 메모리 측정 후 확정한다.
- GitHub Flow와 Conventional Commits. 확인된 사용자 계정으로 커밋하되 AI 기여 기록은 유지한다.
- 공개 GitHub 소스 저장소는 명시 승인됨. 인터넷 서비스 배포·유료 API·클라우드·GPU 사용은 별도 승인 전 보류한다.

세부 구조 결정은 [ADR 0001](decisions/0001-architecture.md)에 기록한다.

## M1 검증 후 보완

- 한국어 Windows 경로에서 Python 3.11 editable `.pth` 디코딩이 실패했다. 환경변수만으로 해결되지 않아 Hatch의 exact editable import와 `editables`를 사용했고 로컬 실행을 확인했다.
- 데이터 정제 v1의 툴팁 용어 소실을 v2에서 수정했다. 외부 포함 정의는 미해결 상태를 명시하고 본격 평가 데이터에 쓰기 전 검수한다.
- 검색 동점이 임의 UUID 순서를 따르지 않도록 파일명·제목·위치·본문 기준 정렬을 먼저 적용했다.
- 평가 파일의 원문·가공·적재 해시를 기록하고 데이터 분할 검사에 근거 annotation까지 포함했다.
- 현재 smoke 질문에서 근거가 없는 질문에도 어휘 일치 결과가 나왔다. 점수 양수만으로 답변 가능 여부를 판단하는 정책은 채택하지 않는다.
- 원격 자동 검사 전까지 로컬 검증만 완료로 표시한다. 서비스 외부 공개는 하지 않는다.
