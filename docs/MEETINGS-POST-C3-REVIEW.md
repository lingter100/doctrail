# C3 종료 뒤 후속 방향 검토

2026-10-15. 기존 `c2_budget_followup` Astra xhigh 역할의 읽기 전용 검토와 부모의 범위 판단이다. 새 실행 계획이나 구현 완료 기록은 아니다. 닫힌 C3의 공개 calibration 진단만 사용했고 validation 본문·test는 열지 않았다. 파일 수정·새 모델 실행·유료 사용은 검토 역할에서0이다.

## 현재 결과가 허용하는 해석

C3의 문제는 JSON이나 인용 좌표에 그치지 않는다. 근거가 충분한 계획에서도 최종 문장이 정보를 누락하거나 새로운 주장을 추가했다. 반대로 질문에 없는 조건을 요구해 잘못 보류한 사례도 있다. 같은 모델에 비슷한 지시문을 반복 적용하면 해결된다는 근거는 확보되지 않았다. 현재6문항을 재실행하거나 예제로 넣지 않는다.

## 비교한 두 방향

| 방향 | 판단과 남은 증거 |
|---|---|
| 자유 생성 뒤 별도 근거·완전성 검증기 | 검증기 자체의 의미 정확성과 교차언어 성능, 자원 비용을 먼저 입증해야 한다. 같은 모델의 자기검토를 독립 검증으로 부르지 않는다. 현재 요청 최대74.781초여서 추가 호출의 지연 여유도 검증되지 않았다. 당장 새 추론을 실행할 근거는 부족하다. |
| 저장된 작업 필드를 결정적 문장으로 조회 | 담당자·기한·등록 상태처럼 좁은 질문에서는 자유 재서술을 줄일 수 있다. 원문 사실, AI 추출, 사용자 수정의 출처를 구분해야 하며 원래 추출의 의미 정확성까지 보증하지 않는다. 새 모델 호출 없이 작게 구현할 수 있다는 검토 의견이다. |

검토 역할은 두 번째를 작은 제품 확장으로 권고했다. **부모는 이를 범용 문서·복수 문서·교차언어 근거 답변의 대체 완료 기준으로 채택하지 않는다.** 사용자가 요구한 자연어 Q&A는 계속 미완료다. 이미 있는 작업 목록과 겹치는 새 기능을 먼저 늘리기보다 현재 기능의 오류 복구와 평가 결과 설명을 마무리한다.

## 다음 실행의 경계

1. 검증된 회의 편집 복구를 보존하고, 별도 감사에서 확인한 목록 조회 실패/실제 빈 결과 혼동을 다음 독립 제품 수정으로 처리한다.
2. 다음 AI 후보는 C3 실패 중 어떤 원인을 바꾸는지와 전체 Q&A 범위를 어떻게 유지하는지부터 명확히 한다. 근거 선택·요구 해석·자유 재서술을 한꺼번에 바꾸고 개선 원인을 특정했다고 주장하지 않는다.
3. 무료 로컬 모델이나 별도 검증기를 바꾼다면 공식 모델 조건·라이선스와 이 PC의 자원 적합성을 먼저 확인한다. 이 문서는 특정 새 모델의 성능이나 실행 가능성을 확인한 기록이 아니다.
4. 근거 있는 작은 구현 방향이 정해진 뒤 새 계약·코드·자료와 독립 평가를 등록한다. 기존 C3 gate를 완화하거나 준비된 validation을 후속 튜닝에 쓰지 않는다. 현재 단계에서는 새 source/question/native 호출0이다.

등록 상태 조회를 별도로 구현하는 경우에도 정보 출처와 지원 범위를 화면에 명시하고, 모호한 대상은 임의 선택하지 않으며 지원하지 않는 질문은 기존 원문 검색으로 연결한다. 이를 C3 성공이나 Phase1 완료로 포장하지 않는다.
