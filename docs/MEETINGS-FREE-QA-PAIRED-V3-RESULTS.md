# 무료 로컬 QA 두 모델 비교 결과

2026-10-30 · 실제 로컬 실행과 별도 AI 내용 판정 · 사용자 검수 아님

**Ministral3-3B 기준과 Qwen2.5-7B 후보 모두 원래 수용 조건을 충족하지 못했다.** 새 모델을 서비스에 채택하지 않는다. 같은 6개를 재실행하거나 이 질문에 맞춰 설정을 바꾸지 않고, 원래 계획대로 이 비교를 종료한다. 무료 로컬 일반 QA와 회의 1차 목표는 아직 미완료다.

## 비교 조건과 결과

같은 실제 출처 6계열·10문서의 봉인 질문 6개를 사용했다. 답변 가능 4개와 보류가 필요한 2개이며, 원래 질문·필수 내용·근거·판정 기준은 출력 전에 고정했다. 입력 4,096토큰·출력 256토큰·요청 60초, 같은 지침·문법·검증기로 비교했다. 모델·양자화·tokenizer·공식 template가 함께 달라지므로 모델 크기만의 효과로 해석하지 않는다.

| 구분 | 기준 3B | 후보 7B |
| --- | ---: | ---: |
| 고정 평가 분모 | 6 | 6 |
| 입력 한도 거절 / 생성 없음 | 1 | 1 |
| 출력 한도 거절 | 2 | 1 |

시간은 시작·준비·보존 확인을 포함한 로컬 실행 1회 값이다. 서비스 응답 시간 분포나 p95가 아니다. 요청 출력상한은 실제 생성 토큰 사용량이나 비용이 아니다. 유료 서비스 호출은 없었으며 전력·장비·개발 보조 비용을 측정하지 않았다.

실제 중립 1회까지 포함한 생성은 11회, 요청 출력상한 합계는 2,816토큰으로 사전 상한 13회·3,328토큰 이내였다. 모든 실행과 관찰 세션은 종료했고, 알려진 소유 프로세스 5개씩의 부재를 확인했다. 재시도·부분 출력 수선·보충 실행은 없었다. ## 길이 제한과 내용 품질은 별개다

저장된 숫자 기록에서 FQA01 입력은 기준 5,134·후보 5,237토큰으로 확인됐다. 두 모델 모두 입력 한도를 넘겨 생성 전에 거절했다. 기준 FQA03·04와 후보 FQA04는 각각 실제 출력 256토큰과 `stop_type=limit`을 기록해 완결 출력 조건에서 거절됐다. 형식 유효한 나머지 출력은 종료 토큰으로 끝났지만 독립 내용 기준을 충족하지 못했다.

입력 길이와 출력 잘림의 원인은 확인했지만, 예산을 늘리면 충분하고 정확한 답변이 나온다는 결론은 낼 수 없다. 후보의 형식 유효가 한 건 증가한 것도 의미 품질 개선을 입증하지 않는다. 거절한 부분 출력을 완성된 답변처럼 채점하거나 유리한 출력만 합치지 않았다.

## 판정과 해석의 한계

구현·실행에 참여하지 않은 별도 AI 평가자가 원래 기준으로 유효 출력 7개 전부를 판정했다. 자동 거절 5개도 고정 분모에 남겼다. 개별 판단을 잠근 뒤 모델 대응표를 공개했다. 다만 평가자는 상속된 진행 정보 일부를 보았으므로 완전한 블라인드라고 주장하지 않는다. AI 판정이며 사용자·외부 사람 검수는 아니다.

이 작은 개발 진입 시험의 0/6은 일반 정답률이나 모든 무료 로컬 모델의 한계를 뜻하지 않는다. 검색기·권한·문서 버전·화면을 포함한 최종 서비스 평가도 아니다. 원래 [6/6 선택 규칙과 실패 종료 규칙](MEETINGS-FREE-QA-NEXT-DECISION.md)을 유지하며 다음 모델·프롬프트를 자동 탐색하지 않는다. 격리 validation과 최종 test는 이 비교의 튜닝에 사용하지 않았다.

현재 소스 `9236b85`의 양쪽 [필수 CI](../experiments/results/meetings-free-qa-paired-v3-ci-v1.json)는 Python 5,384개·제외 21개, 브라우저 158개씩과 실제 Java HTTP·합성 운영 검사를 통과했다. 이 회귀 성공은 모델 내용 수용 0/6을 대체하지 않는다.

## 다음 작업
