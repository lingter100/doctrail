# C3 validation source 부분 노출 이탈 기록

2026-10-14 · 설계 판단 `c2_budget_followup` / 부모가 확인한 실제 `gpt-6-astra / xhigh`. 부모 모델 변경을 뜻하지 않는다. 이 역할과 부모는 후보 설계 참여 때문에 독립 출력 채점에서 계속 제외된다. 사건 영수증은 `data/evaluation/meetings-c3-source-exposure-v1.json`이다.

**결론: 원래 부모 비노출 조건의 실제 위반을 보존한 채, 기존 source와 예정된 validation8 절차를 조건부 계속할 수 있다.** 이는 완전 비노출 validation의 복구나 기존 계약 무위반 판정이 아니다. 새 pool이나 질문 회피 규칙을 만들어 노출을 지우지 않는다. 코드·prompt·상한·점수·cal6/6 및 val8/8 gate는 그대로이며, 아직 어느 품질 gate도 통과했다는 뜻이 아니다.

## 실제 사건과 확인 범위

부모는 staged whitespace 검사 `git -c core.whitespace=cr-at-eol diff --cached --check`의 출력을 직접 받아 validation source4개 중3개의 내용 일부에 의도치 않게 노출됐다고 보고했다. 공개 문서1개의 **본문 일반설명문장1줄**과 합성 문서2개의 머리말9줄, 총10줄이다. 합성 머리말에는 문서번호, 회의/기록일·시간, 프로그램/작품 제목, 연결 문서 표기, 기록 담당자가 포함된다. 실제 문자열은 이 설계자에게 전달되지 않았으며 재열람하지 않았다.

본문1줄과 머리말의 날짜·역할·대상 정보는 모두 실제 source 내용이다. 이를 “metadata만 보았음” 또는 “validation 의미본문 미노출”로 축소하지 않는다. 부모 보고상 합성 문서의 논의·결정 본문은 노출되지 않았고, 당시 validation 질문/oracle는 아직0이었다. **향후 질문의 사실이나 근거와 노출 내용이 겹치지 않는다고 확인할 수 없다.** 노출 영향이0이라는 주장도 하지 않는다.

이 사건 범위와 당시 변경/호출0은 부모의 자기보고이며, 이 역할이 실제 출력이나 validation 원문을 독립 대조한 결과가 아니다. 이 역할은 STATUS의 단계 메타데이터와 원 실행 계약·명확화 문서만 확인했다. 사건 시각은 source freeze 작성 후/커밋 전이라는 순서만 알려졌으며 정확한 시각을 만들지 않는다. 이전 STATUS의 “부모 원문 미열람” 문장은 사건 전 상태다. 이후 전체 기간을 설명하는 비노출 증거로 인용하면 안 된다.

당시 whole toolchain66은 `2f3e9e9` 이전에 동결되고 CI가 통과했다. Calibration source9는 `d02697e`에 고정됐고 calibration6 문항은 별도 검토 중이다. Validation source4/38chunks는 별도 검토4승인/0거절·변경0, Java2통과 후 source freeze9 SHA `abf06680edb3b9e301b53b82931024f98edf8b521322d4c3e9ce19b8c7b89733`이 작성됐으나 아직 커밋 전이었다. 공식 tokenizer/native0이고, 노출에 따른 모델·코드·자료 수정/생성0이라는 부모 보고를 보존한다.

## 계속할 수 있는 범위와 이유

후보·실행·판정 규칙이 노출 전에 고정됐고, 부모는 원래부터 독립 출력 judge가 아니다. 별도 validation custodian과 사전검토자가 자료/문항을 맡고, 아직 질문/oracle/출력이 없는 시점이므로 **노출 후 후보나 자료를 맞추는 경로를 닫고 남은 절차를 수행할 수 있다.** 이 통제는 편향 가능성을 줄일 뿐 원래 비노출 조건을 되돌리거나 통계적 독립성을 증명하지 않는다.

1. 이 문서와 사건 영수증을 먼저 등록하고 부모가 보고 사실을 확인한다. 기존 source bytes와 source freeze를 그대로 커밋한 뒤 격리 저자가 등록된8문항을 작성한다. 노출된 이름·날짜·문장을 피하거나 일부러 묻는 별도 지침을 주지 않는다. 새 source 대체/제외, pool 재선정, 기존 구성·난도·답변가능성 배정을 바꾸지 않는다.
2. 부모는 validation 질문/oracle/context 선택·의미 사전검토에 참여하거나 내용 피드백을 주지 않는다. 격리 저자와 별도 prereviewer는 기존 registry와 계약만으로 문항을 작성·검토한다. 실제 사전검토가 거절한 초안은 기존 절차대로 보존하고 새 버전으로 수정할 수 있지만, 이 노출을 이유로 유리한 항목을 고르거나 거절을 유도하지 않는다.
3. 동결된66/28/72/41/18, 후보 코드·prompt·model·예산·guard·threshold와 모든 source freeze를 수정하지 않는다. 노출 내용을 calibration 수정, 예시 추가, neutral fixture 조정, 후보 튜닝에 쓰지 않는다. Calibration의 독립 item 검토는 계속할 수 있으며 validation 내용은 전달하지 않는다.
4. 기존 순서인 item 사전검토/동결 → 공식 준비 → neutral4 → calibration6 최종 답변 잠금/진단 → cal6/6 gate → validation8 단발 실행/독립 답변 잠금/진단을 유지한다. 이 사건 등록은 이 선행조건을 건너뛰는 실행 허가가 아니다. 기존 중단·재시도0·최대32native·인간0·자동 채택 금지도 유지한다.

## 실제 노출 attestation과 보고 연결

이번 JSON은 **부모/operator의 source 내용 노출 자기보고를 기록한 별도 사건 영수증**이다. Judge의 역할 독립/미열람 attestation을 대신하지 않는다. 두 split의 최종 judge는 pack을 열기 전에 각자의 실제 노출을 새로 등록해야 한다. 이 사건의 범주 요약을 AGENTS 등으로 보았다면 그 사실도 기록하고, 부모의 실제 source 문자열을 본 것과 혼동하지 않는다. 모델/가설/과거 결과 노출·mapping/plan/raw 노출·저자 역할 비참여를 구분한다. 부모나 이 설계자를 새 judge로 지정하지 않는다.

Judge의 `mapping_not_seen`과 `independent_of_authors_and_designers`는 해당 judge 자신의 실제 상태가 충족될 때만 true다. 부모의 부분 source 노출을 이 두 필드에 false로 대입하거나, 두 필드가 true라는 이유로 프로젝트 전체의 validation 비노출를 주장하지 않는다. 현재 split의 plan/mapping 선행 노출·작성 역할 충돌에 대한 기존 잠금 거절은 그대로다.

이 문서와 JSON의 최종 SHA를 source 단계 후속 기록, 실행 등록 부속 기록, 최종 품질 요약/공개 결과의 한계에 연결한다. 고정된66파일 집합이나 strict audit schema에 새 필드를 끼워 넣지 않는다. 아직 만들지 않은 attestation에는 기존 schema가 허용하는 노출 설명을 사용하고, 별도 reporting receipt가 이 사건의 경로/SHA와 attestation·최종 결과 SHA를 연결하게 한다. 동결 artifact나 이미 작성된 과거 상태를 소급 덮어쓰지 않는다.

최종 결과가 gate를 통과해도 “부모에게 validation source 일부가 질문 작성 전에 노출된 상태에서, 사전 동결 후보와 별도 자료/판정 역할로 수행한 평가”라고 명시한다. 완전 비노출·원래 격리조건 무위반·노출 무영향·새 holdout 복구를 주장하지 않는다. 아직 적합성/완전성/품질 결과는 없다.

기존 C2 사건은 **출력 judge**의 모델/가설/과거 결과 metadata 노출 뒤 label-masked 사후 진단을 수행한 사건이다. 이번은 **후보 설계에 참여한 부모**의 실제 validation source 일부 노출이며, 아직 출력 평가 전이다. C2의 진단 허용을 이번 노출의 자동 면제로 쓰거나 이번 사건만으로 미래 C3 judge가 같은 노출을 했다고 기록하지 않는다.

## 재노출 방지와 중단 경계

부모는 validation을 포함한 diff/whitespace 검사 stdout·stderr를 처음부터 `.local`의 별도 파일로 저장하고 원문을 console/tool 응답으로 출력하지 않는다. 부모에게 필요한 것은 종료 상태, 건수, hash 등 내용 없는 요약이다. 본문을 볼 수 있는 custodian만 필요한 원인 확인을 한다. 원본 공백을 수정해 경고를 없애거나 노출 재현 목적으로 검사를 다시 출력하지 않는다. 기존 사건 출력은 원래 기록으로 보존하며 이 문서에 복사하지 않는다.

보고 범위보다 넓은 노출, 부모의 내용 지시, 노출에 따른 후보/자료 변경, 독립 judge의 금지된 plan/mapping 선행 노출이 발견되면 관련 다음 단계/추가 호출을 중단하고 **새 사건 기록으로 따로 판단**한다. 이 문서가 그 경우까지 계속할 권한을 주지 않는다. Cal gate 실패·준비/자원/실행 오류 등 원래 중단 사유도 그대로 적용한다. 실패 뒤 source나 질문을 교체해 같은 C3를 통과시키지 않는다.

현재 보고된 범위만으로 전체 pool 폐기나 사용자 재승인이 필요하다는 규칙은 원 계약에 없다. 기존 자율 진행 범위 안의 별도 이탈 등록이며, 이 문서는 새 자료·질문·추론을 수행하지 않았다. 무료/로컬, phase1/PR14 미완료/draft, human0를 유지한다.
