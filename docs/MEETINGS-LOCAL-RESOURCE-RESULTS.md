# 로컬 자원 정책 실제 비교 결과

2026-10-26 · 무료 로컬 개발 비교 · 서비스 채택 안 함

**실제 모델 생성 8건 모두 응답 검사를 통과하지 못했다.** 고정 항목 처리는 종료됐지만 유효 요약·답변이 없어 1차 기능 품질 완료로 보지 않는다.

| 정책 | native-rss6-host2-v1, 시작8GiB / native RSS6GiB / 호스트여유2GiB |

[실제 결과](../experiments/results/meetings-local-resource-actual-v1.json), [준비 검증](../experiments/results/meetings-local-resource-preparation-v1.json), [구현](../experiments/results/meetings-local-resource-envelope-v1.json), [정확 소스 CI](../experiments/results/meetings-local-resource-policy-source-ci-v1.json)를 구분해 보존한다.

외부 시작 관측은9,516,060,672B, native 시작 직전 내부 관측은9,330,892,800B였다. 둘은 별개의 단일 관측이며 통과할 때까지 반복 측정한 것이 아니다. 실행 중 표본 최대 native RSS는2,941,214,720B, 표본 최소 호스트 가용량은5,473,984,512B였다. 장치 전체 VRAM 표본 최대3,172MiB는 이 모델의 독점 사용량이 아니다. 이 한 번의 관측으로 다른 부하·모든 입력에서6GiB가 충분하거나 OS가2GiB를 예약한다고 결론 내리지 않는다.

이번에는8개의 생성 요청이 발행돼 입력단계 거부가 발생하지 않았다. 앞선 v2의 입력한도 거부8건과 이후 v3의 두 시작조건 거부는 그대로 보존한다. 이번 실행은 compact 입력과 별도 자원 정책을 사용하므로 단일 변수의 순수 모델 우열 비교라고 부르지 않는다.

요청한 출력 예산 합계4096은 실제 생성토큰 수나 내용 품질 점수가 아니다. 공식 판정은 종료가 길이 제한에 걸린4건과 JSON형식 거부4건이다. 왜 해당 형태가 생성됐는지는 별도의 구조 진단으로 확인한다. 잘린 출력이나 펜스를 사후 수정해 성공으로 바꾸지 않는다.

유효 parsed 출력이 없어 의미 충분성·정답률을 계산하지 않았다. 관측된 지표는 응답 검사 수용0/8이며, 이를 사실 정확도0%나 다른 모델보다 열등하다는 일반 결론으로 바꾸지 않는다. 원문·질문·기준·사람 검수 상태도 변경하지 않는다.

원본 응답8·봉인파일66과 이전 실험을 보존했고, 부모가 코드·자산 상태·이전 고정 참조와 소유 프로세스 종료를 대조한 뒤 코드 고정을 해제했다. 같은 등록은 소비됐으며 재실행하지 않는다. 다음 작업은 저장된 응답의 구조적 실패 원인을 분류하고 근거 있는 별도 개입을 설계하는 것이다. 실제 모델 의미 품질·서비스 최종 연결·사용자 검수·공개 배포는 남아 있다.

후속 [구조 진단](../experiments/results/meetings-local-resource-structure-v1.json)에서8개모두코드펜스임을확인했다. EOS4개는펜스내부JSON만성립했고limit4개는실제cap도달로미완결이었다. EOS요약의모든주장5개는근거5~9개로기존최대4개를위반했다. EOS QA3개는확인한필요구조조건만만족했으며근거존재나의미정답은미검증이다. 저장입력은2,275~3,184토큰이었다. 원래파서오판을뒷받침하는증거는없고수용0/8은그대로다. [새형식설계](MEETINGS-LOCAL-FORMAT-NEXT.md)는생성grammar만별도로시험하며현재구현/성공결과가아니다.
