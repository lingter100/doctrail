# 고정 엔진 소스의 일반 파일 모드 처리

2026-10-30. [v6 실제 취득](../experiments/results/meetings-summary-engine-v6-acquisition-v1.json)은 시간 초과가 아니라 `source_type` 검사로 실패했다. 컴파일·모델 실행 전의 수집 코드 오류이며 요약 품질 결과가 아니다.

저장된 공식 Git tree를 원래 순서대로 확인했다. 선택된 파일 1,687개 중 5개는 일반 blob이면서 모드가 `100755`였다. 첫 거절 항목은 `ggml/src/ggml-cann/CMakeLists.txt`다. 원래 코드는 `100644`만 허용했기 때문에 정상 파일을 거부했다. 기존 보존 목록에는 앞선 53개 소스의 경로·크기가 정확히 일치했고, 거절된 첫 파일은 다운로드되지 않았다.

고정 엔진 commit은 `d81235049384534c167caea52b85a694f6103d14`, tree는 `a47b4d437e9769fc34c0116371412b5af5de67d1`이다. 저장된 tree JSON의 SHA-256은 `11d9bbbd5ec89c14ef1fd9865b6a5b5084640b25fce6ff9efb4d09e0170cc518`이다. 이 진단은 해당 공개 메타데이터와 기존 파일 목록만 사용했으며 파일 실행이나 취득 재시도는 없었다.

수정은 일반 blob의 두 모드 `100644`와 `100755`를 허용하는 조건 한 곳으로 제한한다. 실행 비트는 다운로드할 소스의 Git 속성으로 취급한다. 파일 실행 권한이나 허용 프로세스를 추가하지 않는다. symlink·gitlink·알 수 없는 종류와 모드, 금지 payload, 경로 이탈은 계속 거부하며 원래 commit·blob·크기·해시 검증도 유지한다.

거절된 파일들이 꺼진 GPU backend 디렉터리에도 있다는 이유로 해당 소스를 빼지는 않는다. 고정 소스 선택을 유지하고 정상 파일 속성만 정확히 처리하는 편이 더 작은 수정이다. 소스 manifest와 이후 검증에는 모드 전제가 없으므로 스키마·런타임·관찰 도구 변경은 필요하지 않다.

집중 검사는 두 일반 모드의 정상 취득과 잘못된 blob 거절, 실제 경로·모드를 재현한 합성 본문, symlink·gitlink·비정상 모드의 다운로드 전 거절을 확인했다. 첫10개 통과와 새 검사 참조 오류12개 실패를 보존했고, 실패12개만 수정 후 통과했다. 서로 다른22개 사례의 통과 증거와 정상 Ruff 결과를 [검사 기록](../experiments/results/meetings-summary-source-mode-repair-v1.json)에 남겼다. 초기 출력 인코딩 오류의 원시 로그도 유지한다. 독립 변경 검토·게시 CI 상태는 [현재 상태](STATUS.md)를 따른다.

이 수정만으로 전체 취득·컴파일·요약 품질 성공을 주장하지 않는다. v6 실패·부분 파일·소비 기록은 유지하며 새 취득을 자동 재시도하지 않는다.
