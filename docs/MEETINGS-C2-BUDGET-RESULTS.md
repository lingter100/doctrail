# C2 공통 입력 한도 비교의 실패와 사후 진단

이 결과는 **모델·이전 결과 metadata에 노출된 AI 검토자의 label-masked 사후 진단**이다. 검토자는 자료 작성·설계에 참여하지 않았고 표본과 방식의 대응표를 판정 잠금 전에 보지 않았지만, 완전한 맹검 조건은 충족하지 못했다. [정보 노출 방법 수정](MEETINGS-C2-BUDGET-REVIEW-EXPOSURE.md)과 [결과 연결 영수증](../experiments/results/meetings-c2-budget-partial-diagnostic-v1/reporting-receipt.json)을 반드시 함께 읽는다. 사람 검수는 0이다.

## 실행과 판정 범위

사전 봉인한 공통 입력 5,120 / 출력 384 / context 6,144 조건으로 calibration 16회 중 15회를 실제 실행했다. 첫 14개 응답 뒤 C2-CAL-08/C2가 영어 요청에 한국어 claim을 출력해 언어 검사를 실패했다. 마지막 L0 1회는 실행하지 않았고 격리 validation도 열지 않았다. 이 시점에 전체 8쌍 선택 기준은 실패했다. 출력 수정, 남은 호출 재개, 재시도는 없다.

이후 별도 고정한 도구로 기존 14개 응답의 raw/native/mapper를 재생하고, 실패한 15번째도 같은 언어 오류로 재현했다. 익명 14개 판정을 모두 작성한 뒤 잠금 파일을 만들고 그 뒤에만 대응표를 결합했다. 이 사후 작업의 새 모델·토크나이저 호출은 0이다.

| 지표 | L0 줄 단위 | C2 문맥 단위 |
|---|---:|---:|
| 진단 대상 응답 | 7 | 7 |
| 완전 정답 | 1/7 | 1/7 |
| 주장 근거 지지 실패 | 4/7 | 2/7 |
| 질문의 필수 내용 누락 | 5/7 | 6/7 |
| 답변/보류 선택 오류 | 0/7 | 1/7 |

두 방식 합계 정확한 원문 인용은 47/47이다. 인용이 정확하다는 것은 그 인용이 모든 주장을 지지하거나 답변이 질문 전체를 해결한다는 뜻이 아니다. 짝별 완전 정답 기준으로 개선 1건과 퇴보 1건이 관측됐다. 부분 표본·사후 진단·검토자 정보 노출 때문에 우월성 추론에 사용하지 않는다. 언어 실패 1건과 미실행 1건은 표의 의미 점수에 넣지 않았다.

## 확인한 실패

- CAL-01: L0는 선택하지 않은 다음 줄에 있는 승인자 역할까지 주장했다. C2는 두 역할의 완전한 문맥을 인용해 이 사례를 회복했다.
- CAL-02/03: 문맥 인용 안에 정답 정보가 있어도 회사별 인원 상한, 선거 시점, 예외 조건, 후보자의 수락 절차 등을 답변 본문에서 누락했다. 넓은 인용만으로 내용 완전성을 확보할 수 없다.
- CAL-04: 빈도는 있지만 실제 최근 회의 날짜는 없는 복합 질문이다. L0는 전체 질문을 보류했고 C2는 일부 정보로 답변을 만들었다. C2의 넓은 인용도 자료 전체에서 날짜가 없다는 주장의 근거가 되지 않는다.
- CAL-05/06/07: 적용 날짜·담당자·다음 근무자의 기록 의무·검사 보류와 재검사 단계를 빠뜨렸다. 특히 CAL-07은 시각 네 개를 맞혀도 요청한 전체 순서와 담당자를 설명하지 못했다.
- CAL-08: 영어 요청에 한국어 답변을 반환했다. 3,730 입력/126 출력/EOS였으므로 이 오류를 출력 한도 초과로 설명하지 않는다.

사후 진단은 원인을 확정하는 실험이 아니다. 질문 요구사항별 근거·누락 확인이 필요하다는 가설을 뒷받침하지만, 새 접근의 효과는 새 자료와 별도 실제 실행으로 검증해야 한다. 같은 8문항을 고쳐 맞추거나 미개방 검증 12개로 튜닝하지 않는다.
